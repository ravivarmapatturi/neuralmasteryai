# Learning quality rubric

Review each dimension from 0 (absent), 1 (partial), to 2 (clear and verified). Total /20. A major lesson targets 16; a flagship lesson targets 18. Scores require human review of rendered content; automated source counts are only triage.

| Dimension | What earns 2 |
| --- | --- |
| Content | Defines the idea, explains why it exists, mechanism, use, and failure |
| Visual explanation | A diagram clarifies a relationship and has an explanatory caption |
| Interactivity | Controls change computed state and explain the consequence |
| Practice | A relevant task checks understanding or implementation |
| Navigation | Prerequisites and next step are clear |
| Accessibility | Keyboard, labels, contrast, and nonvisual description work |
| Mobile | Content, math, tables, and controls work at 390px |
| Performance | Page-specific bundles and visuals stay responsive |
| Technical correctness | Equations, code, and claims are checked |
| Production relevance | Trade-offs and real-world failure modes are explicit |

Definition of done: render and inspect desktop/mobile and both themes; check keyboard operation, code, math, links, build, and relevant tests. Record evidence for each lesson before assigning a final score.
