# MLOps — Roadmap

Everything between "a model that works in a notebook" and "a model that reliably serves real traffic, gets monitored, and retrains itself." Assumes [Machine Learning](/docs/machine-learning/roadmap) and [Deep Learning](/docs/deep-learning/roadmap) — this section is about running models in production, not training them.

## 16. [LLM Inference Engines](/docs/mlops/llm-inference-engines)

- [x] Engine vs framework vs platform: inference engine *executes* the model, serving framework *exposes* it as an API, hosting platform *provides* the infrastructure, fine-tuning framework *trains/adapts* it (not the same job as an inference engine)
- [x] Tier 1: vLLM, SGLang, llama.cpp, TensorRT-LLM, Hugging Face TGI, ONNX Runtime, OpenVINO
- [x] Tier 2: NVIDIA Triton (general-purpose multi-framework serving, distinct from LLM-specific engines), DeepSpeed-Inference, ExecuTorch, MLX, MLC-LLM, Apache TVM, Ray Serve
