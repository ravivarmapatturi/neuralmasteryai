# Agent Architecture Atlas

A capable model does not determine whether an agent finishes a long task. The surrounding control flow decides what the model sees, which actions it may take, how failures change the next attempt and what survives when one context window ends. This atlas follows the architectures that made those decisions explicit, in date order.

<ELI5>

Think of preparing a complex meal. A prompt chain is a recipe with fixed steps. A tool loop lets the cook inspect each result before choosing what to do next. A supervisor gives separate jobs to several cooks. A harness keeps the recipe, ingredients, timers, safety rules and progress notes organized, so another shift can continue the meal without guessing what happened.

</ELI5>

## The Architecture Surrounds the Model

These entries did not replace one another. A production research agent can route the request, ask an orchestrator to create parallel searches, run each worker as a ReAct loop, compact the findings into a smaller context and store a cited report for the next session. The architecture is the set of choices that connects those parts and limits their behavior.

The diagrams show control flow, not model internals. When a system fails, identify which layer made the decision: the model, the tool interface, the router, the memory policy, the graph transition or the durable harness.
