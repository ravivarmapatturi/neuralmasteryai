# PCA, Kernel PCA & Truncated SVD

[Unsupervised Learning](/docs/machine-learning/unsupervised-learning) asked whether data with $d$ features can be described with far fewer numbers. Principal component analysis is the standard answer: find the few directions along which the data varies most, and describe each point by its position along those. This page derives PCA twice, as the directions of maximum variance and as the best low-dimensional approximation, and shows both lead to the same eigenvectors, which are also the singular vectors of the data matrix. It then covers how many components to keep, why scaling changes the answer, kernel PCA for curved structure, and truncated SVD for sparse data such as text. Everything is checked numerically against scikit-learn.

<ELI5>

Picture a swarm of bees flying along a straight country road. To tell a friend where each bee is, you could give three numbers: east-west, north-south, and height. But most of the information is in one number, how far along the road the bee is. Width across the road and height vary a little, but not much. Describing each bee by "distance along the road" loses very little.

PCA finds that road automatically: the direction along which the points spread out the most, then the next most spread-out direction at right angles to it, and so on. Keep the first few, drop the rest, and you've described the data with fewer numbers while losing as little as possible. Everything below is that idea made exact.

</ELI5>

## 1. The Direction of Greatest Variance

### PCA: Principal Component Analysis

Start with $n$ points in $d$ dimensions, stacked as the rows of $X$, and **centre** them by subtracting each feature's mean, so the cloud sits at the origin. The covariance matrix is

$$
S = \frac{1}{n-1}X^TX
$$

a $d \times d$ symmetric matrix: entry $S_{jk}$ is the covariance of features $j$ and $k$.

Project every point onto a unit vector $\mathbf{w}$: point $i$ becomes the single number $\mathbf{w}^T\mathbf{x}_i$. The variance of these numbers is

$$
\operatorname{Var}(\mathbf{w}^T\mathbf{x}) = \frac{1}{n-1}\sum_i(\mathbf{w}^T\mathbf{x}_i)^2 = \mathbf{w}^T S\,\mathbf{w}
$$

The first principal component is the unit direction that makes this as large as possible:

$$
\max_{\mathbf{w}}\;\mathbf{w}^TS\mathbf{w} \quad\text{subject to}\quad \mathbf{w}^T\mathbf{w} = 1
$$

(Without the constraint, scaling $\mathbf{w}$ up would make the variance infinite.) Add a Lagrange multiplier $\lambda$ for the constraint and set the gradient to zero:

$$
\nabla_{\mathbf{w}}\big[\mathbf{w}^TS\mathbf{w} - \lambda(\mathbf{w}^T\mathbf{w} - 1)\big] = 2S\mathbf{w} - 2\lambda\mathbf{w} = 0 \quad\Rightarrow\quad S\mathbf{w} = \lambda\mathbf{w}
$$

So $\mathbf{w}$ must be an **eigenvector** of the covariance matrix (see [Linear Algebra: Eigenvalues](/docs/mathematics-for-ai/linear-algebra#eigenvalues-and-eigenvectors)). Which one? Multiply both sides by $\mathbf{w}^T$: the variance along it is $\mathbf{w}^TS\mathbf{w} = \lambda\mathbf{w}^T\mathbf{w} = \lambda$. **The variance along an eigenvector is its eigenvalue**, so the first principal component is the eigenvector with the largest eigenvalue.

The second component is the direction of greatest variance among those perpendicular to the first; repeating the argument with that extra constraint gives the eigenvector with the second-largest eigenvalue, and so on. Because $S$ is symmetric, its eigenvectors are mutually orthogonal and its eigenvalues are real and non-negative, so the result is a new orthogonal coordinate system, ordered by how much of the data's variance each axis carries. The total variance is unchanged by the rotation: $\sum_j\lambda_j = \operatorname{tr}(S)$, the sum of the original features' variances.

**Reducing dimension** means keeping the top $k$ eigenvectors as the columns of a $d \times k$ matrix $W_k$, and replacing each point by its $k$ coordinates $\mathbf{z}_i = W_k^T\mathbf{x}_i$. ## 2. The Same Answer From Reconstruction

There's a second way to ask for "the best $k$-dimensional summary": find the $k$-dimensional subspace that the points are closest to. Project each point onto a subspace with orthonormal basis $W_k$ and map it back, $\hat{\mathbf{x}}_i = W_kW_k^T\mathbf{x}_i$. The reconstruction error is the squared distance from each point to its projection. Because $\hat{\mathbf{x}}_i$ and $\mathbf{x}_i - \hat{\mathbf{x}}_i$ are perpendicular, Pythagoras gives

$$
\lVert\mathbf{x}_i - \hat{\mathbf{x}}_i\rVert^2 = \lVert\mathbf{x}_i\rVert^2 - \lVert W_k^T\mathbf{x}_i\rVert^2
$$

Summed over points, the first term is fixed. So **minimizing reconstruction error is the same as maximizing the variance captured** by the subspace, and the best subspace is spanned by the top $k$ eigenvectors. The leftover error has a clean value: divided by $n - 1$, it equals the sum of the discarded eigenvalues,

$$
\frac{1}{n-1}\sum_i\lVert\mathbf{x}_i - \hat{\mathbf{x}}_i\rVert^2 = \sum_{j \gt  k}\lambda_j
$$

Section 6 checks this on the handwritten-digits data for $k = 5, 10, 20, 40$, and the two columns agree to every printed digit. The Eckart–Young theorem says the same thing for matrices: the best rank-$k$ approximation of $X$, in squared error, is its truncated SVD, which is where the next section goes.

## 3. PCA Is the SVD of the Centred Data

Write the centred data matrix by its [singular value decomposition](/docs/mathematics-for-ai/linear-algebra#singular-value-decomposition-svd), $X = U\Sigma V^T$, where $U$ ($n \times d$) and $V$ ($d \times d$) have orthonormal columns and $\Sigma$ holds the singular values $\sigma_1 \ge \sigma_2 \ge \dots$. Then

$$
S = \frac{1}{n-1}X^TX = \frac{1}{n-1}V\Sigma U^TU\Sigma V^T = V\,\frac{\Sigma^2}{n-1}\,V^T
$$

since $U^TU = I$. That's an eigendecomposition of $S$. So:

- The **principal directions** are the right singular vectors, the columns of $V$.
- The **variances** are $\lambda_j = \sigma_j^2/(n-1)$.
- The **projected coordinates** of the data are $XV = U\Sigma$: the left singular vectors scaled by the singular values.

Libraries compute PCA through the SVD rather than by forming $S$, for the reason on the [Linear Regression page](/docs/machine-learning/linear-regression#9-minimal-implementation): forming $X^TX$ squares the condition number and loses precision. For large matrices where only the top $k$ components are needed, **randomized SVD** (Halko, Martinsson and Tropp, 2011) finds them in roughly $O(ndk)$ time instead of $O(nd\min(n, d))$, and it's what scikit-learn uses by default for large inputs.

## 4. How Many Components, and Whose Variance?

**Choosing $k$.** The fraction of variance kept by $k$ components is $\sum_{j \le k}\lambda_j / \sum_j\lambda_j$. The **scree plot** shows each component's share and the running total:

<ThemedImage alt="Scree plot for the digits data: bars showing each of 64 components' share of variance falling quickly, and a cumulative curve crossing 90% at 21 components" sources={{light: screeLight, dark: screeDark}} />

Common rules: keep enough components for a target share (90% or 95% is typical), look for an elbow where the bars flatten, or, when PCA feeds a model, treat $k$ as a hyperparameter and pick it by cross-validation. For the digits, 21 of 64 components keep 90% of the variance, and 40 keep 98.8%.

**Scaling changes the answer.** PCA maximizes variance, and variance depends on units. If one feature is measured in thousands and the rest in fractions, the first component simply points along the large feature. In Section 6, on the raw wine data, the first component carries 99.8% of the variance, almost entirely the proline measurement, which has the largest numbers; after standardizing each feature, it carries 36.2%, spread across several measurements. Standardize (PCA on the correlation matrix) when features have different units; leave them unscaled when they share units and their variances are meaningful, as with pixel intensities.

**Whitening.** Dividing each component by $\sqrt{\lambda_j}$ gives coordinates that are uncorrelated with unit variance (`PCA(whiten=True)`). It's a useful preprocessing step for some methods, and it's the first step of [ICA](/docs/machine-learning/ica-tsne-umap).

<GoDeeper title="Go deeper: probabilistic PCA and what PCA assumes">

PCA can be written as a probability model. Tipping and Bishop (1999) defined **probabilistic PCA**: each point is generated from a $k$-dimensional latent variable $\mathbf{z} \sim \mathcal{N}(0, I)$ by a linear map plus isotropic noise, $\mathbf{x} = W\mathbf{z} + \boldsymbol{\mu} + \boldsymbol{\epsilon}$ with $\boldsymbol{\epsilon} \sim \mathcal{N}(0, \sigma^2I)$. They showed the maximum-likelihood $W$ spans the same subspace as the top $k$ principal components, and the maximum-likelihood $\sigma^2$ is the average of the discarded eigenvalues: the variance PCA throws away is treated as noise.

That makes PCA's assumptions explicit: the important structure is linear, and what remains is noise of equal size in every direction. It also gives PCA a likelihood, which allows choosing $k$ with BIC, handling missing values with EM, and mixing several local PCA models. **Factor analysis** relaxes the equal-noise assumption, giving each feature its own noise variance, which matters when features are measured with different precision.

</GoDeeper>

## 5. Beyond Linear: Kernel PCA and Truncated SVD

**Kernel PCA.** PCA finds straight directions. For curved structure, map the data through features $\phi(\mathbf{x})$ and do PCA there, using the [kernel trick](/docs/machine-learning/support-vector-machines#the-kernel-trick) to avoid computing $\phi$. Every principal direction in feature space is a combination of the mapped training points, $\mathbf{w} = \sum_i\alpha_i\phi(\mathbf{x}_i)$, and substituting this into the eigenvector equation turns it into an eigenproblem for the $n \times n$ kernel matrix $K_{ij} = k(\mathbf{x}_i, \mathbf{x}_j)$ (Schölkopf, Smola and Müller, 1998). The mapped points must be centred in feature space, which is done on the kernel matrix directly: $\tilde{K} = HKH$, with the centring matrix $H = I - \tfrac1n\mathbf{1}\mathbf{1}^T$. The eigenvectors of $\tilde{K}$ give the $\alpha$ coefficients, and a point's coordinate on a component is $\sum_i\alpha_i\tilde{k}(\mathbf{x}_i, \mathbf{x})$.

Section 6 runs it on two concentric rings, which no straight direction separates (one linear component gives about 49% accuracy for a classifier, chance level). With a degree-2 polynomial kernel, whose features are $x_1^2$, $\sqrt{2}x_1x_2$ and $x_2^2$, one kernel component separates the rings perfectly (100%). But it's the *third* component, not the first. The radius, $x_1^2 + x_2^2$, is what separates the rings, yet it varies less than other combinations of the squared features. PCA ranks directions by variance, never by usefulness for a task you haven't told it about: the most variable direction and the most informative one can be different.

Kernel PCA costs $O(n^2)$ memory and up to $O(n^3)$ time for the eigendecomposition, it needs a kernel and its parameters chosen, and its components are hard to interpret. It's mainly useful on moderate data where curved structure matters.

### Truncated SVD

PCA centres the data first. For a **sparse** matrix, such as a document-term matrix where each row is a document and almost every word count is zero, centring is a disaster: subtracting the column means turns every zero into a nonzero, and a matrix that fit in memory because it was 99.9% empty becomes completely dense. In Section 6, a 20,000 × 5,000 sparse matrix stores 100,000 values; centred, it would need all 100,000,000.

**Truncated SVD** skips centring and computes the top $k$ singular vectors of the raw matrix directly, with sparse-aware randomized or iterative solvers. Without centring, the first component mostly captures the mean, and the rest are similar to PCA's. On text this is called **latent semantic analysis** (LSA; Deerwester et al., 1990): words that occur in similar documents end up with similar coordinates, so documents can be compared by topic even when they share few exact words. It's scikit-learn's `TruncatedSVD`, and the standard dimensionality reduction for TF-IDF features.

## 6. Minimal Implementation

PCA two ways on the 64-pixel digits data, the reconstruction-error identity, the effect of scaling on wine data, kernel PCA on concentric rings, and truncated SVD on a sparse matrix:

```python
import numpy as np
from scipy import sparse
from sklearn.datasets import load_digits, load_wine, make_circles
from sklearn.decomposition import PCA, KernelPCA, TruncatedSVD
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score
from sklearn.preprocessing import StandardScaler

X, _ = load_digits(return_X_y=True)                      # 1,797 images, 64 pixels each
Xc = X - X.mean(0)

# PCA two ways: eigenvectors of the covariance matrix, and the SVD of the centred data
S = Xc.T @ Xc / (len(X) - 1)
evals, evecs = np.linalg.eigh(S)
evals, evecs = evals[::-1], evecs[:, ::-1]                # largest first
U, sing, Vt = np.linalg.svd(Xc, full_matrices=False)
sk = PCA().fit(X)
print("top 3 variances, eigenvalues:      ", np.round(evals[:3], 2))
print("top 3 variances, sigma^2/(n-1):    ", np.round(sing[:3] ** 2 / (len(X) - 1), 2))
print("top 3 variances, scikit-learn:     ", np.round(sk.explained_variance_[:3], 2))
print("same directions (up to sign):", np.allclose(np.abs(evecs[:, :10]), np.abs(Vt[:10].T), atol=1e-6))

# Reconstruction error with k components equals the sum of the discarded eigenvalues
for k in [5, 10, 20, 40]:
    Z = Xc @ evecs[:, :k]                                # project
    err = np.sum((Xc - Z @ evecs[:, :k].T) ** 2) / (len(X) - 1)
    print(f"k={k:<3} reconstruction error {err:9.2f}   sum of discarded eigenvalues {evals[k:].sum():9.2f}   "
          f"variance kept {evals[:k].sum() / evals.sum():.1%}")

# Scaling changes the answer: wine features have very different units
W, _ = load_wine(return_X_y=True)
raw = PCA(2).fit(W).explained_variance_ratio_
std = PCA(2).fit(StandardScaler().fit_transform(W)).explained_variance_ratio_
print(f"wine, first component's share of variance: raw {raw[0]:.1%}, standardized {std[0]:.1%}")

# Kernel PCA on concentric circles: which single component separates the two rings?
Xr, yr = make_circles(n_samples=600, factor=0.4, noise=0.05, random_state=0)
Zlin = PCA(2).fit_transform(Xr)
Zker = KernelPCA(3, kernel="poly", degree=2, coef0=0).fit_transform(Xr)   # features x1^2, sqrt(2) x1 x2, x2^2
acc = lambda z: cross_val_score(LogisticRegression(), z[:, None], yr, cv=5).mean()
print("linear PCA, accuracy from component 1, 2:     ", [float(round(acc(Zlin[:, j]), 3)) for j in range(2)])
print("kernel PCA, accuracy from component 1, 2, 3:  ", [float(round(acc(Zker[:, j]), 3)) for j in range(3)])

# Truncated SVD on a sparse matrix: centring would make it dense
rng = np.random.default_rng(0)
M = sparse.random(20000, 5000, density=0.001, format="csr", random_state=0)
svd = TruncatedSVD(50, random_state=0).fit(M)
print(f"sparse matrix: {M.nnz:,} stored values of {M.shape[0] * M.shape[1]:,}; "
      f"after centring every one of the {M.shape[0] * M.shape[1]:,} would be nonzero")
print(f"truncated SVD to 50 components: transformed shape {svd.transform(M).shape}")
```

- **Three routes, one answer (Sections 1 and 3).** Covariance eigenvalues, $\sigma^2/(n-1)$ from the SVD, and scikit-learn agree, and the eigenvectors match the right singular vectors up to sign (an eigenvector's sign is arbitrary).
- **Reconstruction error is discarded variance (Section 2)**, exactly, at every $k$.
- **Units decide the first component (Section 4)**: 99.8% raw, 36.2% standardized.
- **Variance isn't usefulness (Section 5).** The ring-separating kernel component is the third, not the first.
- **Truncated SVD keeps sparse data sparse**, reducing 5,000 columns to 50 without ever forming the dense matrix.

## 7. When *Not* to Use PCA

| Situation | Better choice |
|---|---|
| The structure is curved (a manifold) and you want to see it | [t-SNE or UMAP](/docs/machine-learning/ica-tsne-umap) for visualization; kernel PCA on moderate data |
| The goal is separating classes, and labels are available | Supervised reduction such as [LDA](/docs/machine-learning/naive-bayes-lda-qda); high variance isn't the same as discriminative |
| You need to un-mix independent signals | [ICA](/docs/machine-learning/ica-tsne-umap) |
| Features must stay interpretable | Feature selection (L1, importance) instead; components mix every original feature |
| Sparse, high-dimensional data (text) | Truncated SVD (no centring) |
| Heavy outliers | Robust PCA; a few extreme points can swing the top components |
| Nonnegative data where parts should add up (images, spectra, topics) | Nonnegative matrix factorization (NMF) |

PCA is the right first step for compressing correlated numeric features, removing noise, speeding up a downstream model, and getting a first look at high-dimensional data.

## Remember

| Idea | In one line |
|---|---|
| Objective | Maximize $\mathbf{w}^TS\mathbf{w}$ subject to $\lVert\mathbf{w}\rVert = 1$ |
| Solution | $S\mathbf{w} = \lambda\mathbf{w}$: principal components are covariance eigenvectors |
| Eigenvalue | The variance along that component |
| Reconstruction | Best rank-$k$ subspace; error $= \sum_{j\gt k}\lambda_j$ |
| SVD | $X = U\Sigma V^T$: directions $V$, variances $\sigma^2/(n-1)$, scores $U\Sigma$ |
| Computation | Via the SVD, not $X^TX$; randomized SVD for large data |
| Choosing $k$ | Target variance share, scree elbow, or cross-validation downstream |
| Scaling | Standardize features with different units, or the largest one wins |
| Kernel PCA | Eigenvectors of the centred kernel matrix $HKH$ |
| Caution | Components are ranked by variance, not by usefulness for your task |
| Truncated SVD | No centring; keeps sparse data sparse; LSA for text |
