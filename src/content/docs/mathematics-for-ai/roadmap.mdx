# Mathematics for AI — Roadmap

<ELI5>

Machine learning combines vectors, gradients, probability and computational cost. Learning these foundations in sequence makes later model derivations easier to follow.

</ELI5>

The math you actually need before the rest of this site makes sense. Work top to bottom; each module unlocks the next.
