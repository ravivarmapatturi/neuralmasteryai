# Mathematics for AI

The math on this site is split across the chapters that need it. This page collects it into five modules. Each module lists where the idea is taught, where it is used, and a few problems you can solve in the browser to check you have it.

Work through the modules in order if you are starting out. Probability comes first because a model's output is a distribution, and every loss we train on is a statement about that distribution.

## Module 1: Probability

What a model's output means. A classifier's softmax is a categorical distribution; a language model samples from one per token.

- Learn: [Random variables and distributions](/docs/mathematics-for-ai/probability-statistics#random-variables-and-distributions), [Bayes' theorem](/docs/mathematics-for-ai/probability-statistics#bayes-theorem), [MLE vs MAP](/docs/mathematics-for-ai/probability-statistics#mle-vs-map)
- Learn: [Entropy, cross-entropy and KL divergence](/docs/mathematics-for-ai/probability-statistics#entropy-cross-entropy-and-kl-divergence)
- Used in: [Naive Bayes, LDA and QDA](/docs/machine-learning/naive-bayes-lda-qda), [Logistic regression](/docs/machine-learning/logistic-regression), [Loss functions](/docs/deep-learning/loss-functions)
- Practice: [Softmax](/practice/softmax), [Bayes posterior](/practice/bayes-posterior), [Categorical cross-entropy](/practice/categorical-cross-entropy), [Distillation KL loss](/practice/loss-distillation-kl)

## Module 2: Statistics

Whether to trust a number. An accuracy of 91% on 200 examples and 91% on 20,000 examples are different claims, and statistics is how we say by how much.

- Learn: [Expectation, variance, covariance](/docs/mathematics-for-ai/probability-statistics#expectation-variance-covariance), [Central limit theorem](/docs/mathematics-for-ai/probability-statistics#central-limit-theorem)
- Learn: [Hypothesis testing](/docs/mathematics-for-ai/probability-statistics#hypothesis-testing-significance), [Bootstrap and permutation tests](/docs/mathematics-for-ai/probability-statistics#bootstrap-and-permutation-tests)
- Used in: [Model evaluation metrics](/docs/machine-learning/model-evaluation-metrics), [Uncertainty estimation and conformal prediction](/docs/machine-learning/uncertainty-estimation-and-conformal-prediction)
- Practice: [Mean squared error](/practice/mean-squared-error)

## Module 3: Linear algebra

How data and weights are stored and combined. An embedding is a vector, a layer is a matrix, and attention is a batch of dot products.

- Learn: [Vectors](/docs/mathematics-for-ai/linear-algebra#vectors), [Matrices](/docs/mathematics-for-ai/linear-algebra#matrices), [Rank, independence and span](/docs/mathematics-for-ai/linear-algebra#rank-independence-and-span)
- Learn: [Eigenvalues](/docs/mathematics-for-ai/linear-algebra#eigenvalues-and-eigenvectors), [SVD](/docs/mathematics-for-ai/linear-algebra#singular-value-decomposition-svd)
- Used in: [PCA and truncated SVD](/docs/machine-learning/pca-svd), [Attention and transformers](/docs/deep-learning/attention-transformers), [Embedding space explorer](/docs/visual-lab/embedding-space-explorer)
- Practice: [Dot product](/practice/dot-product), [Matrix multiplication](/practice/matrix-multiplication), [Cosine similarity](/practice/cosine-similarity), [Scaled dot-product attention](/practice/attn-scaled-dot-product)

## Module 4: Calculus

How a model learns which way to move. Backpropagation is the chain rule applied to a graph of operations, one node at a time.

- Learn: [Derivatives and gradients](/docs/mathematics-for-ai/calculus-optimization#derivatives-and-gradients), [Jacobians and Hessians](/docs/mathematics-for-ai/calculus-optimization#jacobians-hessians-derivatives-of-vector-valued-and-multivariate-functions)
- Learn: [The chain rule and backpropagation](/docs/mathematics-for-ai/calculus-optimization#the-chain-rule-backpropagation), [Matrix calculus](/docs/mathematics-for-ai/linear-algebra#matrix-calculus-gradients-wrt-vectors-and-matrices)
- Used in: [Neural network fundamentals](/docs/deep-learning/neural-network-fundamentals), [Activation functions](/docs/deep-learning/activation-functions)
- Practice: [Numerical gradient](/practice/numerical-gradient), [Sigmoid derivative](/practice/sigmoid-derivative)

## Module 5: Optimisation

How to take the steps. The gradient gives a direction; the optimiser decides how far to go and how to remember past steps.

- Learn: [Convexity](/docs/mathematics-for-ai/calculus-optimization#convexity), [Gradient descent and its variants](/docs/mathematics-for-ai/calculus-optimization#gradient-descent-and-its-variants), [Lagrange multipliers and KKT](/docs/mathematics-for-ai/calculus-optimization#constrained-optimization-lagrange-multipliers-kkt-conditions)
- Learn: [Optimizers](/docs/deep-learning/optimizers), [Initialization, regularization and schedules](/docs/deep-learning/initialization-regularization-scheduling)
- Used in: [SGD classifier and regressor](/docs/machine-learning/sgd-classifier-regressor), [Support vector machines](/docs/machine-learning/support-vector-machines), [Hyperparameter optimization](/docs/machine-learning/hyperparameter-optimization)
- Try it: [Gradient descent explorer](/docs/visual-lab/gradient-descent-explorer)
- Practice: [Gradient descent step](/practice/gradient-descent-step), [AdamW](/practice/adamw-optimizer), [Gradient clipping by global norm](/practice/opt-clip-grad-norm), [Momentum vs SGD](/practice/opt-momentum-vs-sgd), [Warmup plus cosine decay](/practice/opt-warmup-cosine)
