```python
def pairwise_manhattan_distance(x, y):
    res = []
    for u in x:
        row = []
        for v in y:
            d = sum(abs(a - b) for a, b in zip(u, v))
            row.append(round(float(d), 4))
        res.append(row)
    return res
```

Manhattan distance measures city-block distance along coordinate axes, less sensitive to extreme coordinate outliers than Euclidean distance.
