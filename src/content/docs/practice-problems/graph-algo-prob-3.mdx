```python
def compute_node_degrees(n, edges):
    degrees = {i: 0 for i in range(n)}
    for u, v in edges:
        degrees[u] += 1
        degrees[v] += 1
    return degrees
```

Initialize degree counts to zero for all n vertices, then iterate through edges incrementing the degree counter for both connected endpoints.
