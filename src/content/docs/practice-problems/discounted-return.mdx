**Difficulty: Easy** · Concept: [RL Fundamentals — Markov Decision Processes (MDPs)](/docs/reinforcement-learning/rl-fundamentals#markov-decision-processes-mdps)

An RL agent doesn't just care about the very next reward — it cares about the total reward it can expect going forward, the **return**. Future rewards are discounted by a factor $\gamma \in [0, 1]$ per timestep, so a reward $k$ steps away counts for $\gamma^k$ of its face value:

$$G_t = \sum_{k=0}^{T} \gamma^k r_{t+k}$$

$\gamma$ close to `1` means the agent is nearly as concerned with far-future rewards as immediate ones ("far-sighted"); $\gamma$ close to `0` means it barely looks past the next step ("short-sighted"). This return, not any single reward, is what value functions ([Policies and Value Functions](/docs/reinforcement-learning/rl-fundamentals#policies-and-value-functions)) are actually trying to predict.

**Your task**: implement `discounted_return(rewards, gamma)`, where `rewards` is a list `[r_0, r_1, ..., r_T]` in time order.

<Solution>

```python
def discounted_return(rewards, gamma):
    return sum(gamma ** k * r for k, r in enumerate(rewards))
```

`enumerate` gives each reward its timestep offset `k` directly, so `gamma ** k * r` is a direct transcription of $\gamma^k r_{t+k}$ for each term, and `sum` adds them up. `gamma = 1.0` degenerates to plain undiscounted total reward (test 1: `1+1+1 = 3`) — a useful sanity check, since $\gamma^k = 1$ for every $k$ when $\gamma=1$. `gamma = 0.5` on four `1`s gives `1 + 0.5 + 0.25 + 0.125 = 1.875` — each further-out reward counting for exactly half of the one before it, visibly converging toward (but never reaching) $\frac{1}{1-\gamma} = 2$ as more terms are added, which is *why* $\gamma < 1$ keeps the return finite even for an infinite-horizon task with constant reward, where plain undiscounted summing would diverge to infinity.

This return is the actual quantity a value function $V(s) = \mathbb{E}[G_t \mid s_t = s]$ is defined to predict, and the [Bellman equations](/docs/reinforcement-learning/rl-fundamentals#the-bellman-equations) are exactly the recursive relationship that falls out of this sum's own structure — $G_t = r_t + \gamma G_{t+1}$, one reward now plus the (discounted) rest of the same sum, one step later.
