```python
def simplify_path(path):
    tokens = path.split('/')
    stack = []
    for t in tokens:
        if t == '' or t == '.':
            continue
        elif t == '..':
            if stack: stack.pop()
        else:
            stack.append(t)
    return '/' + '/'.join(stack)
```

Splitting on slash and managing directory push/pop operations normalizes paths in linear time.
