## Overview

Compute the determinant of 1x1, 2x2, or 3x3 square matrices.

## Task

Implement `matrix_determinant(A)`: calculate det(A) for matrices of dimension up to 3x3 using direct algebraic formulas / Laplace cofactor expansion. Round result to 4 decimals.

<Solution>

```python
def matrix_determinant(A):
    n = len(A)
    if n == 1:
        return round(float(A[0][0]), 4)
    if n == 2:
        return round(float(A[0][0] * A[1][1] - A[0][1] * A[1][0]), 4)
    if n == 3:
        det = (A[0][0] * (A[1][1] * A[2][2] - A[1][2] * A[2][1])
             - A[0][1] * (A[1][0] * A[2][2] - A[1][2] * A[2][0])
             + A[0][2] * (A[1][0] * A[2][1] - A[1][1] * A[2][0]))
        return round(float(det), 4)
    return 0.0
```

Evaluates closed-form determinant formulas for low dimensions up to 3x3.
