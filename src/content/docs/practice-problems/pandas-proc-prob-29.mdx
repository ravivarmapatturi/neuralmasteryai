```python
def watermark_stream_filter(stream, max_delay):
    wm = -float('inf')
    accepted, rejected = [], []
    for ev in stream:
        ts = ev['timestamp']
        if ts < wm:
            rejected.append(ev)
        else:
            accepted.append(ev)
            wm = max(wm, ts - max_delay)
    return {'accepted_events': accepted, 'rejected_events': rejected}
```

Updates the low-watermark threshold and filters out late-arriving temporal events.
