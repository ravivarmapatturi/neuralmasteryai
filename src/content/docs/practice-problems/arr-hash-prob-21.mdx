## Overview

Implement `trap_rain_water(height)` via precomputed left-max/right-max arrays -- the classic hard array problem, keyed on the insight that water trapped at any position depends only on the shorter of the tallest walls on either side.

## Task

Implement the function `trap_rain_water(height)`: `height[i]` is the height of a bar at position `i` in an elevation map. Return the total units of rainwater trapped between the bars after it rains.
