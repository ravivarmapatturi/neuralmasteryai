## Overview

Implement `max_area(heights)`, the greedy two-pointer solution to Container With Most Water -- the classic proof that checking every pair is unnecessary once you see why moving the shorter pointer is always the only move worth making.

## Task

Implement the function `max_area(heights)`: `heights[i]` is the height of a vertical line at position `i`. Return the maximum area a pair of these lines (plus the x-axis between them) can contain.
