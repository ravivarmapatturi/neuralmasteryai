```python
def find_redundant_connection(edges):
    n = len(edges)
    parent = list(range(n + 1))
    def find(i):
        if parent[i] == i:
            return i
        parent[i] = find(parent[i])
        return parent[i]
    for u, v in edges:
        ru, rv = find(u), find(v)
        if ru == rv:
            return [u, v]
        parent[ru] = rv
    return []
```

Process edges into a Disjoint Set Union data structure. The first edge whose endpoints already belong to the same connected component creates a cycle.
