```python
def find_swapped_values_bst(root):
    first, second, prev = None, None, None
    curr = root
    stack = []
    while stack or curr:
        while curr:
            stack.append(curr)
            curr = curr.get('left')
        curr = stack.pop()
        if prev and prev['val'] > curr['val']:
            if not first:
                first = prev
                second = curr
            else:
                second = curr
        prev = curr
        curr = curr.get('right')
    res = [first['val'], second['val']]
    res.sort()
    return res
```

Perform an iterative inorder traversal. An error creates one or two inversions where `prev.val > curr.val`. The first mistake is prev and the second mistake is curr.
