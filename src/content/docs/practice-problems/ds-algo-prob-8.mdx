```python
import copy

def flood_fill(image, sr, sc, color):
    orig = image[sr][sc]
    if orig == color:
        return image
    img = copy.deepcopy(image)
    rows, cols = len(img), len(img[0])

    def dfs(r, c):
        if r < 0 or r >= rows or c < 0 or c >= cols or img[r][c] != orig:
            return
        img[r][c] = color
        dfs(r+1,c); dfs(r-1,c); dfs(r,c+1); dfs(r,c-1)

    dfs(sr, sc)
    return img
```

Early-exit when `orig == color` prevents infinite recursion. DFS marks each cell before recursing to avoid revisiting. O(m*n) time, O(m*n) recursion stack.
