```python
def min_camera_cover(root):
    cameras = 0
    def dfs(node):
        nonlocal cameras
        if not node:
            return 2
        left = dfs(node.get('left'))
        right = dfs(node.get('right'))
        if left == 0 or right == 0:
            cameras += 1
            return 1
        if left == 1 or right == 1:
            return 2
        return 0
    if dfs(root) == 0:
        cameras += 1
    return cameras
```

Use a 3-state bottom-up postorder traversal. A node installs a camera if and only if at least one child is uncovered. If the root itself remains uncovered after traversal, add one final camera.
