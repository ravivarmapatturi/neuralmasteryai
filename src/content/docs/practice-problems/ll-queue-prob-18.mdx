```python
def flatten_multilevel_list(head):
    if not head:
        return None
    dummy = {'val': 0, 'next': None}
    prev = dummy
    stack = [head]
    while stack:
        curr = stack.pop()
        prev['next'] = {'val': curr['val'], 'next': None}
        prev = prev['next']
        if curr.get('next'):
            stack.append(curr['next'])
        if curr.get('child'):
            stack.append(curr['child'])
    return dummy['next']
```

Using a LIFO stack prioritizing child pointers before next pointers produces the canonical depth-first linear ordering.
