## Overview

Implement `top_k_frequent(nums, k)` to return the `k` most common numbers in an array, utilizing frequency counting and bucket sorting.

## Task

Implement the function `top_k_frequent(nums, k)`: return the `k` most frequent elements in `nums`, ordered by frequency descending (ties broken by value ascending).
