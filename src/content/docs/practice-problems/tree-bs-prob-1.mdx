## Overview

Implement `max_depth(root)`, the simplest possible tree recursion, and the one every other "compute something about every subtree" tree problem is a variation of.

## Task

Implement the function `max_depth(root)`: each tree node is a dict `{'val', 'left', 'right'}` (or `None` for an empty tree/absent child). Return the number of nodes along the longest path from root to the farthest leaf; an empty tree has depth `0`.
