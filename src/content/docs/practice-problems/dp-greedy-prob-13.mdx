```python
def longest_increasing_subsequence(nums):
    import bisect
    tails = []
    for x in nums:
        idx = bisect.bisect_left(tails, x)
        if idx == len(tails):
            tails.append(x)
        else:
            tails[idx] = x
    return len(tails)
```

For each number, find its insertion point in tails via binary search. Replace the first element `>= x` or append if x is strictly greater than all tails.
