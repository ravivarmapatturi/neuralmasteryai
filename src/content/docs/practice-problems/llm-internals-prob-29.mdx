## Overview

Compute the cross-entropy loss for a single-token prediction from raw logits and true target index.

## Task

Implement `cross_entropy_loss(logits, target_idx)`. Apply numerically stable softmax by subtracting `max(logits)`, then return `-log(p_target)` rounded to 4 decimal places. Raise `ValueError` if `logits` is empty, or `IndexError` if `target_idx` is out of bounds.
