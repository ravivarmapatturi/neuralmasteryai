```python
import math

def gmm_e_step_1d(x, weights, means, variances):
    res = []
    for val in x:
        densities = []
        for w, m, v in zip(weights, means, variances):
            std = math.sqrt(max(1e-9, v))
            exp_term = math.exp(-0.5 * ((val - m) ** 2) / max(1e-9, v))
            pdf = (1.0 / (std * math.sqrt(2.0 * math.pi))) * exp_term
            densities.append(w * pdf)
        total = sum(densities)
        if total > 0.0:
            row = [round(float(d / total), 4) for d in densities]
        else:
            row = [round(1.0 / len(weights), 4)] * len(weights)
        res.append(row)
    return res
```

The E-step applies Bayes theorem to calculate the soft probability responsibility of each Gaussian component for generating each observation.
