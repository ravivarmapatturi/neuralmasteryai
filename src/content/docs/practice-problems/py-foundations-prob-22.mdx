## Overview

Implement an O(n) moving average window filter by maintaining incremental running sums.

## Task

Implement `sliding_window_average(nums, k)`: calculate the moving average for each continuous sub-array of length `k` across `nums`. Each mean must be rounded to 4 decimal places. If `len(nums) < k` or `k <= 0`, return `[]`.

<Solution>

```python
def sliding_window_average(nums, k):
    if k <= 0 or len(nums) < k:
        return []
    window_sum = sum(nums[:k])
    result = [round(window_sum / k, 4)]
    for i in range(k, len(nums)):
        window_sum += nums[i] - nums[i - k]
        result.append(round(window_sum / k, 4))
    return result
```

Adding the new element and subtracting the element sliding out of the window updates the sum in O(1) operations per element.

</Solution>
