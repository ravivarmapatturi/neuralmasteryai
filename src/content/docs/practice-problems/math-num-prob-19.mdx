## Overview

Evaluate fundamental information-theoretic metrics on discrete probability distributions.

## Task

Implement `shannon_and_cross_entropy(p, q)`: compute base-2 Shannon entropy `H(p) = -sum(p_i * log2(p_i))`, cross-entropy `H(p, q) = -sum(p_i * log2(q_i))`, and Kullback-Leibler divergence `D_KL(p || q) = H(p, q) - H(p)`. Skip terms where `p_i < 1e-12`. Return `{"entropy_p": float, "cross_entropy": float, "kl_div": float}` rounded to 4 decimals.

<Solution>

```python
import math

def shannon_and_cross_entropy(p, q):
    entropy_p = -sum(pi * math.log2(pi) for pi in p if pi > 1e-12)
    cross_entropy = -sum(pi * math.log2(qi) for pi, qi in zip(p, q) if pi > 1e-12 and qi > 1e-12)
    kl_div = cross_entropy - entropy_p
    return {'entropy_p': round(float(entropy_p), 4), 'cross_entropy': round(float(cross_entropy), 4), 'kl_div': round(float(kl_div), 4)}
```

Computes self-information expectation for entropy and relative entropy via logarithmic differences in base 2.
