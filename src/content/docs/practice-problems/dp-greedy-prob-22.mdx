```python
def max_product_subarray(nums):
    if not nums:
        return 0
    max_prod = nums[0]
    curr_min = nums[0]
    curr_max = nums[0]
    for x in nums[1:]:
        candidates = (x, curr_max * x, curr_min * x)
        curr_max = max(candidates)
        curr_min = min(candidates)
        if curr_max > max_prod:
            max_prod = curr_max
    return max_prod
```

Negative numbers turn minimum products into maximum products. By tracking both curr_min and curr_max at every step, we evaluate all sign flips in O(n) time and O(1) space.
