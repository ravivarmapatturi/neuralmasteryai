```python
def sliding_window_median(stream, window_size):
    if not stream or window_size <= 0:
        return []
    res = []
    for i in range(window_size - 1, len(stream)):
        win = sorted(stream[i - window_size + 1 : i + 1])
        mid = len(win) // 2
        if len(win) % 2 == 1:
            med = win[mid]
        else:
            med = (win[mid - 1] + win[mid]) / 2.0
        res.append(round(float(med), 4))
    return res
```

Rolling medians filter out impulse noise and spikes in streaming sensor telemetry much more robustly than moving averages.
