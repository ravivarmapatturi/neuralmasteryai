```python
def divisor_game(n):
    return n % 2 == 0
```

If n is even, Alice can always subtract 1 to pass Bob an odd number. An odd number only has odd divisors, so Bob must subtract an odd number, returning an even number to Alice. Eventually Bob receives 1 and loses.
