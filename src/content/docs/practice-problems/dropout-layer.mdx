Implement inverted dropout for regularizing neural network activations during training.

<Solution>

```python
def dropout(x, drop_prob, mask):
    if drop_prob >= 1.0:
        return [0.0] * len(x)
    scale = 1.0 / (1.0 - drop_prob)
    return [val * m * scale for val, m in zip(x, mask)]
```

Dropout prevents feature co-adaptation by randomly zeroing activations with probability p during training.

</Solution>
