```python
def precision_recall_at_k(recommended, relevant, k):
    top_k = recommended[:k]
    rel_set = set(relevant)
    hits = sum(1 for item in top_k if item in rel_set)
    precision = hits / k if k > 0 else 0.0
    recall = hits / len(rel_set) if len(rel_set) > 0 else 0.0
    return {"precision": round(float(precision), 4), "recall": round(float(recall), 4)}
```

Precision@K measures the proportion of recommended items that are useful, while Recall@K measures the proportion of all relevant items captured in top-k.
