```python
def simulate_token_bucket(requests, rate, capacity):
    tokens = float(capacity)
    last_time = requests[0] if requests else 0.0
    allowed = []
    for t in requests:
        elapsed = t - last_time
        tokens = min(float(capacity), tokens + elapsed * rate)
        last_time = t
        if tokens >= 1.0:
            tokens -= 1.0
            allowed.append(True)
        else:
            allowed.append(False)
    return allowed
```

Calculating token replenishment lazily upon request arrival avoids background polling timers while ensuring exact traffic shaping.
