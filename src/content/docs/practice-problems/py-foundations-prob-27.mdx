## Overview

Simulate the industry-standard Token Bucket traffic-shaping algorithm for API throttling and LLM rate limiting.

## Task

Implement `simulate_token_bucket(requests, rate, capacity)`: the bucket starts at full `capacity`. At each arrival timestamp `t`, compute replenished tokens `(t - last_time) * rate` (capped at `capacity`). If `tokens >= 1.0`, consume 1.0 and record `True`, otherwise reject and record `False`.

<Solution>

```python
def simulate_token_bucket(requests, rate, capacity):
    tokens = float(capacity)
    last_time = requests[0] if requests else 0.0
    allowed = []
    for t in requests:
        elapsed = t - last_time
        tokens = min(float(capacity), tokens + elapsed * rate)
        last_time = t
        if tokens >= 1.0:
            tokens -= 1.0
            allowed.append(True)
        else:
            allowed.append(False)
    return allowed
```

Calculating token replenishment lazily upon request arrival avoids background polling timers while ensuring exact traffic shaping.

</Solution>
