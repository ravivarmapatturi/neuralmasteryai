```python
def solve_triangular_system(L, b, lower=True):
    n = len(b)
    x = [0.0] * n
    if lower:
        for i in range(n):
            sum_known = sum(L[i][j] * x[j] for j in range(i))
            x[i] = (b[i] - sum_known) / L[i][i]
    else:
        for i in range(n - 1, -1, -1):
            sum_known = sum(L[i][j] * x[j] for j in range(i + 1, n))
            x[i] = (b[i] - sum_known) / L[i][i]
    return [round(float(val), 4) for val in x]
```

Substitutes solved variables into successive equations, operating in O(n^2) time.
