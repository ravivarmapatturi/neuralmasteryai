## Overview

Estimate the dominant eigenvalue and eigenvector of a matrix via repeated matrix-vector multiplication.

## Task

Implement `power_iteration(A, num_iters=20)`: initialize vector `b = [1.0]*n`. At each iteration compute `b_next = A * b` and normalize `b = b_next / ||b_next||`. After `num_iters`, compute the Rayleigh quotient eigenvalue `lambda = (b . A*b) / (b . b)`. Return `{"eigenvalue": float, "eigenvector": list[float]}` rounded to 4 decimals.

<Solution>

```python
import math

def power_iteration(A, num_iters=20):
    n = len(A)
    b = [1.0] * n
    for _ in range(num_iters):
        b_next = [sum(A[i][j] * b[j] for j in range(n)) for i in range(n)]
        norm = math.sqrt(sum(x ** 2 for x in b_next))
        if norm < 1e-9:
            break
        b = [x / norm for x in b_next]
    Ab = [sum(A[i][j] * b[j] for j in range(n)) for i in range(n)]
    rayleigh = sum(b[i] * Ab[i] for i in range(n))
    return {'eigenvalue': round(float(rayleigh), 4), 'eigenvector': [round(float(x), 4) for x in b]}
```

Repeatedly multiplies by A and normalizes, projecting out non-dominant eigen-components, then evaluates Rayleigh quotient.
