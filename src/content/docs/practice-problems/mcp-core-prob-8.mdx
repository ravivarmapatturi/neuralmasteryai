## Overview

Implement request/response correlation by id, the real mechanism an MCP client uses to route an async response back to the code that's waiting for it.

## Task

Implement `correlate_response(pending_requests, response_id)`. `pending_requests` maps request id -> the method name that was called. Return the method name for `response_id`, or `'unknown'` if `response_id` isn't a pending request.
