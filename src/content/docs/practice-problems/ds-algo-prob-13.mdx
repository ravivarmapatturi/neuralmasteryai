```python
from collections import deque

def bfs_shortest_path(graph, start, end):
    if start == end:
        return 0
    visited = {start}
    q = deque([(start, 0)])
    while q:
        node, dist = q.popleft()
        for neighbor in graph.get(node, []):
            if neighbor == end:
                return dist + 1
            if neighbor not in visited:
                visited.add(neighbor)
                q.append((neighbor, dist + 1))
    return -1
```

BFS explores all nodes at distance d before d+1. First time `end` is reached gives the shortest path. O(V+E) time and space.
