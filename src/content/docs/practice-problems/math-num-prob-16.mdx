## Overview

Compute the unbiased empirical sample covariance matrix from multidimensional observations.

## Task

Implement `sample_covariance_matrix(data)`: given an n x d matrix of observations (n rows, d columns), calculate the d x d sample covariance matrix using Bessel's correction `Cov(j1, j2) = sum_i ((x_i,j1 - mu_j1)*(x_i,j2 - mu_j2)) / (n - 1)`. If n `<` 2, return all zeros. Round each entry to 4 decimals.

<Solution>

```python
def sample_covariance_matrix(data):
    n = len(data)
    d = len(data[0]) if n > 0 else 0
    if n < 2:
        return [[0.0] * d for _ in range(d)]
    means = [sum(data[i][j] for i in range(n)) / n for j in range(d)]
    cov = []
    for j1 in range(d):
        row = []
        for j2 in range(d):
            val = sum((data[i][j1] - means[j1]) * (data[i][j2] - means[j2]) for i in range(n)) / (n - 1)
            row.append(round(float(val), 4))
        cov.append(row)
    return cov
```

Subtracts column-wise sample means and normalizes centered inner products by n - 1.
