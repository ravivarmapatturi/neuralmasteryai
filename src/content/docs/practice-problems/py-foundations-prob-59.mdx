```python
def evaluate_ast(node, env):
    ntype = node.get('type')
    if ntype == 'num':
        return float(node.get('val', 0.0))
    elif ntype == 'var':
        return float(env.get(node.get('name'), 0.0))
    elif ntype == 'binop':
        op = node.get('op')
        left = evaluate_ast(node.get('left'), env)
        right = evaluate_ast(node.get('right'), env)
        if op == '+':
            return left + right
        elif op == '-':
            return left - right
        elif op == '*':
            return left * right
        elif op == '/':
            return left / right
    return 0.0
```

Tree recursion visits AST subnodes in post-order, computing operators from leaf values up to root.
