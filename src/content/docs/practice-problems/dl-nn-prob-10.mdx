```python
import math

def categorical_cross_entropy(probs: list[list[float]], targets: list[int], eps: float = 1e-12) -> float:
    N = len(probs)
    total_loss = 0.0
    for i in range(N):
        c = targets[i]
        p = max(probs[i][c], eps)
        total_loss += -math.log(p)
    return round(total_loss / N, 4)
```

Because ground truth targets are one-hot, the cross-entropy collapses to the negative log-probability of the true target class.
