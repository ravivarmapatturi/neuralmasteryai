```python
def unique_paths(m, n):
    dp = [[1] * n for _ in range(m)]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i-1][j] + dp[i][j-1]
    return dp[m-1][n-1]
```

2-D DP: first row and column are all 1s (only one way to reach them). Fill remaining cells as sum of cell above and cell to the left. O(m*n) time, reducible to O(n) space.
