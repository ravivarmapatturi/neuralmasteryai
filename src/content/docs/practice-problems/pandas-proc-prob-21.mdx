```python
def generate_polynomial_interactions(records, feature_cols):
    out = []
    n = len(feature_cols)
    for r in records:
        row = dict(r)
        for i in range(n):
            for j in range(i, n):
                f1, f2 = feature_cols[i], feature_cols[j]
                val = float(r.get(f1, 0.0)) * float(r.get(f2, 0.0))
                row[f'{f1}*{f2}'] = round(float(val), 4)
        out.append(row)
    return out
```

Iterates over upper-triangular index pairs and injects cross-product interaction columns.
