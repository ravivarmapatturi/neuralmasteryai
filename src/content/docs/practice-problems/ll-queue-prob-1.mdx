## Overview

Implement iterative linked-list reversal `reverse_list(head)` -- the single most-repeated linked-list pattern, and the building block half of the other linked-list problems in this track quietly depend on.

## Task

Implement the function `reverse_list(head)`: each node is a dict `{'val', 'next'}` (`None` terminates the list). Return the head of the reversed list, using three tracking pointers in a single O(n) pass.
