```python
from collections import defaultdict

def encode_with_rare_grouping(categories, min_count, rare_label):
    counts = defaultdict(int)
    for c in categories:
        counts[c] += 1
    return [c if counts[c] >= min_count else rare_label for c in categories]
```

Rare category grouping prevents high-cardinality explosion and protects models against overfitting to sparse categories.
