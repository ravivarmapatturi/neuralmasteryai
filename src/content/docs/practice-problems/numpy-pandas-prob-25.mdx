```python
import math

def normalize_columns_l2(matrix):
    if not matrix or not matrix[0]:
        return []
    rows = len(matrix)
    cols = len(matrix[0])
    col_norms = []
    for c in range(cols):
        s = sum(matrix[r][c] ** 2 for r in range(rows))
        col_norms.append(math.sqrt(s))
    res = []
    for r in range(rows):
        row = []
        for c in range(cols):
            val = matrix[r][c] / col_norms[c] if col_norms[c] > 0.0 else 0.0
            row.append(round(val, 4))
        res.append(row)
    return res
```

Column normalization standardizes feature variances and scales in multi-feature regression and dimensionality reduction.
