## Overview

Implement `min_window(s, t)` to discover the smallest contiguous window of `s` containing every character in `t` in linear time.

## Task

Implement the function `min_window(s, t)`: return the minimum window substring of `s` that covers all characters of `t`, or `""` if no such substring exists.
