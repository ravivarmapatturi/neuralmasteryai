## Overview

Implement `cosine_similarity(a, b)`, the default relevance metric behind embedding-based semantic search and RAG retrieval, because it measures directional alignment between two vectors while ignoring their magnitude.

## Task

Implement the function `cosine_similarity(a, b)`, returning `(a . b) / (||a|| * ||b||)` for two equal-length numeric vectors `a` and `b`. Raise `ValueError` if `len(a) != len(b)`, or if either vector has zero magnitude (its direction is undefined).
