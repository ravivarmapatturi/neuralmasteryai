```python
def deterministic_reservoir_sample(stream, k, random_floats):
    if not stream or k <= 0:
        return []
    res = list(stream[:k])
    for i in range(k, len(stream)):
        p = random_floats[i - k]
        if p < (k / (i + 1)):
            target_idx = int(p * (i + 1))
            if target_idx < k:
                res[target_idx] = stream[i]
    return res
```

Algorithm R guarantees every stream element has equal probability k/N of selection without knowing total stream length N in advance.
