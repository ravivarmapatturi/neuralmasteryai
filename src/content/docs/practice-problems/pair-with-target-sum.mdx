**Difficulty: Easy** · Pattern: Two Pointers · Concept: [General Coding (DSA) — Core Patterns to Drill](/docs/interview-prep/dsa-coding#core-patterns-to-drill)

Given a list of integers already sorted in ascending order and a `target`, find the indices of the two numbers that add up to `target`. Assume exactly one valid pair exists, and that you can't use the same element twice.

The brute-force answer checks every pair — $O(n^2)$. Sorted input is the tell that a smarter approach exists: **two pointers**, one starting at each end, moving inward based on whether the current sum is too big or too small.

**Your task**: implement `pair_with_target_sum(arr, target)`, returning `[i, j]` with `i < j`.

<Solution>

```python
def pair_with_target_sum(arr, target):
    left, right = 0, len(arr) - 1
    while left < right:
        current = arr[left] + arr[right]
        if current == target:
            return [left, right]
        if current < target:
            left += 1
        else:
            right -= 1
    raise ValueError("no pair sums to target")
```

Start with the widest possible pair (both ends) and narrow in. If the current sum is too small, the *only* way to increase it is to move the left pointer right (every element to the right is $\geq$ the current one, since the array is sorted) — moving `right` left could only make the sum smaller or equal, never bigger, so it can never help. Symmetric logic applies when the sum is too big. Each step eliminates at least one index from consideration, so the pointers can cross at most $n$ times total — $O(n)$ instead of the brute force's $O(n^2)$, and $O(1)$ extra space instead of a hash map's $O(n)$.
