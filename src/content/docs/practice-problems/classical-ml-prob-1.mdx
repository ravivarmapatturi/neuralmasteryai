```python
def mean_squared_error(y_true, y_pred):
    if not y_true:
        return 0.0
    return sum((yt - yp) ** 2 for yt, yp in zip(y_true, y_pred)) / len(y_true)
```

Mean Squared Error heavily penalizes larger outliers due to squaring, making it standard for Gaussian likelihood estimation and ordinary least squares.
