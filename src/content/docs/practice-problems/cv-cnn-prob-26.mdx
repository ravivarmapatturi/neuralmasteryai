```python
def resnet_residual_block(x: list[list[float]], w1: float, w2: float, shortcut_weight: float | None = None) -> list[list[float]]:
    H = len(x)
    W = len(x[0])
    out1 = [[max(0.0, x[i][j] * w1) for j in range(W)] for i in range(H)]
    out2 = [[out1[i][j] * w2 for j in range(W)] for i in range(H)]
    res = [[x[i][j] * shortcut_weight for j in range(W)] for i in range(H)] if shortcut_weight is not None else x
    out = [[round(max(0.0, out2[i][j] + res[i][j]), 4) for j in range(W)] for i in range(H)]
    return out
```

The block learns the residual adjustment F(x) and adds it directly to the identity projection before final rectification.
