**Difficulty: Easy** · Concept: [NN Layers Reference — Normalization Layers](/docs/deep-learning/nn-layers-reference#normalization-layers)

$$\text{LayerNorm}(x)_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma_i + \beta_i, \quad \mu = \text{mean}(x), \ \sigma^2 = \text{var}(x)$$

Unlike [RMSNorm](/practice/rms-normalization), LayerNorm both re-centers (subtracts the mean) and rescales (divides by the standard deviation) — and unlike BatchNorm, it normalizes across a single example's *own* features rather than across the batch, which is exactly why it's batch-size-independent and became the default in Transformers (which often process variable-length sequences one token at a time, where batch statistics are awkward at best).

**Your task**: implement `layer_norm(x, gamma, beta, eps=1e-5)` for a 2D NumPy array `x` of shape `(batch, features)`, normalizing each row independently over its own features.

<Solution>

```python
import numpy as np

def layer_norm(x, gamma, beta, eps=1e-5):
    mean = np.mean(x, axis=-1, keepdims=True)
    var = np.var(x, axis=-1, keepdims=True)
    x_norm = (x - mean) / np.sqrt(var + eps)
    return x_norm * gamma + beta
```

`axis=-1, keepdims=True` is the whole trick: computing mean/variance over the *last* axis (features) rather than `axis=0` (which would be BatchNorm's job instead) means each row gets its own mean and variance, completely independent of every other row in the batch — feed it a batch of one example, or a batch of a million, and row 0's output is identical either way. `keepdims=True` keeps `mean`/`var` as `(batch, 1)` rather than `(batch,)`, so the subtraction and division broadcast correctly against the full `(batch, features)` array instead of raising a shape error.

The constant-row case (`[4, 4, 4]`) is a real edge case worth having a test for: variance is exactly 0, and without `eps` the division would be `0/0`. With `eps=1e-5` it instead cleanly resolves to a real, if slightly-scaled-down, `0` output — no NaN.
