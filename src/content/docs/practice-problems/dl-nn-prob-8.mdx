```python
def dropout_forward(x: list[list[float]], p_drop: float, mask: list[list[int]]) -> list[list[float]]:
    if p_drop >= 1.0:
        return [[0.0 for _ in row] for row in x]
    scale = 1.0 / (1.0 - p_drop)
    out = []
    for i in range(len(x)):
        row = []
        for j in range(len(x[0])):
            val = (x[i][j] * mask[i][j]) * scale
            row.append(round(float(val), 4))
        out.append(row)
    return out
```

Multiplying kept activations by 1/(1 - p) scales up surviving units so the total energy / expected sum of activations matches inference mode.
