## Overview

Apply inverted dropout regularization during training to prevent co-adaptation of feature representations.

## Task

Implement `dropout_forward(x, p_drop, mask)`: given activations `x`, dropout probability `p_drop`, and binary keep-mask `mask` (where `1` means keep, `0` means drop), compute `out[i][j] = (x[i][j] * mask[i][j]) / (1.0 - p_drop)`. Scaling during training ensures that no scaling is required at test time. Round each element to 4 decimal places.

<Solution>

```python
def dropout_forward(x: list[list[float]], p_drop: float, mask: list[list[int]]) -> list[list[float]]:
    if p_drop >= 1.0:
        return [[0.0 for _ in row] for row in x]
    scale = 1.0 / (1.0 - p_drop)
    out = []
    for i in range(len(x)):
        row = []
        for j in range(len(x[0])):
            val = (x[i][j] * mask[i][j]) * scale
            row.append(round(float(val), 4))
        out.append(row)
    return out
```

Multiplying kept activations by 1/(1 - p) scales up surviving units so the total energy / expected sum of activations matches inference mode.

</Solution>
