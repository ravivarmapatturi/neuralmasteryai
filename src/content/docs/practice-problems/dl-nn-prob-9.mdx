## Overview

Accelerate stochastic gradient descent and dampen oscillations along ravines using classical momentum.

## Task

Implement `sgd_momentum_step(param, grad, velocity, lr, momentum)`: for each index `k`, update the velocity as `v_k = momentum * velocity[k] + lr * grad[k]`, and then update the parameter as `param_k = param[k] - v_k`. Return a dictionary `{'param': [...], 'velocity': [...]}` with each float rounded to 6 decimal places.

<Solution>

```python
def sgd_momentum_step(param: list[float], grad: list[float], velocity: list[float], lr: float, momentum: float) -> dict:
    new_v = []
    new_p = []
    for p, g, v in zip(param, grad, velocity):
        v_step = momentum * v + lr * g
        p_step = p - v_step
        new_v.append(round(v_step, 6))
        new_p.append(round(p_step, 6))
    return {"param": new_p, "velocity": new_v}
```

Classical momentum treats parameters as particles moving through a friction-dampened potential landscape: velocity retains history and integrates the current gradient force.

</Solution>
