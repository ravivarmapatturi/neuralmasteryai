```python
def erase_overlap_intervals(intervals):
    if not intervals:
        return 0
    sorted_inv = sorted(intervals, key=lambda x: x[1])
    count = 0
    end = sorted_inv[0][1]
    for start, finish in sorted_inv[1:]:
        if start < end:
            count += 1
        else:
            end = finish
    return count
```

Sort intervals by end time. Always keep the interval that finishes earliest; if a subsequent interval starts before that end time, it must be removed to prevent overlap.
