```python
def huber_loss(y_true, y_pred, delta):
    n = len(y_true)
    if n == 0:
        return 0.0
    total = 0.0
    for yt, yp in zip(y_true, y_pred):
        err = abs(yt - yp)
        if err <= delta:
            total += 0.5 * (err ** 2)
        else:
            total += delta * (err - 0.5 * delta)
    return round(float(total / n), 4)
```

Huber loss transitions smoothly from quadratic MSE for small residuals to linear MAE for large residuals, ensuring robust gradients under heavy-tailed noise.
