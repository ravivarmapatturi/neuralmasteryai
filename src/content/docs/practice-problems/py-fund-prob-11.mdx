```python
import bisect

def cumulative_moving_median(nums):
    if not nums:
        return []
    medians = []
    window = []
    for x in nums:
        bisect.insort(window, x)
        m = len(window)
        if m % 2 == 1:
            med = float(window[m // 2])
        else:
            med = (window[m // 2 - 1] + window[m // 2]) / 2.0
        medians.append(round(med, 4))
    return medians
```

Inserting via bisect maintains sorted order so median extraction takes O(1) time per element.
