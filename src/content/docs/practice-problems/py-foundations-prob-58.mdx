```python
def autocomplete(words_with_scores, prefix, top_k):
    matches = []
    for word, score in words_with_scores:
        if word.startswith(prefix):
            matches.append((score, word))
    matches.sort(key=lambda x: (-x[0], x[1]))
    return [w for _, w in matches[:top_k]]
```

Filtering on prefix followed by sorting with composite key `(-score, word)` cleanly ranks candidate queries.
