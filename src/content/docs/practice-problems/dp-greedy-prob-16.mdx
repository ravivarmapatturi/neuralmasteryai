```python
def min_jumps(nums):
    if len(nums) <= 1:
        return 0
    jumps = 0
    curr_end = 0
    farthest = 0
    for i in range(len(nums) - 1):
        farthest = max(farthest, i + nums[i])
        if i == curr_end:
            jumps += 1
            curr_end = farthest
            if curr_end >= len(nums) - 1:
                break
    return jumps
```

Greedily expand the reachable boundary. Each increment of jumps corresponds to exhausting the reach of the previous jump tier and locking in the best reachable point.
