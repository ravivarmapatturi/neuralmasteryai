```python
def interval_intersections(first_list, second_list):
    i, j = 0, 0
    intersections = []
    while i < len(first_list) and j < len(second_list):
        start = max(first_list[i][0], second_list[j][0])
        end = min(first_list[i][1], second_list[j][1])
        if start <= end:
            intersections.append([start, end])
        if first_list[i][1] < second_list[j][1]:
            i += 1
        else:
            j += 1
    return intersections
```

Comparing boundaries with two pointers and advancing the earlier-ending interval guarantees full linear O(M + N) coverage.
