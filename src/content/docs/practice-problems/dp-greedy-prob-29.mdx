```python
def longest_valid_parentheses(s):
    stack = [-1]
    max_len = 0
    for i, c in enumerate(s):
        if c == '(':
            stack.append(i)
        else:
            stack.pop()
            if not stack:
                stack.append(i)
            else:
                length = i - stack[-1]
                if length > max_len:
                    max_len = length
    return max_len
```

Initialize the stack with -1. Push indices of "(". For ")", pop top. If empty, the current index becomes the new boundary; otherwise the distance to stack top is a valid substring length.
