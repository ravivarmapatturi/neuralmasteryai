```python
import math

def multiclass_log_loss(y_true, pred_probs, eps):
    n = len(y_true)
    if n == 0:
        return 0.0
    total = 0.0
    for yt, probs in zip(y_true, pred_probs):
        clipped = max(eps, min(1.0 - eps, probs[yt]))
        total += -math.log(clipped)
    return round(float(total / n), 4)
```

Clipping probabilities to [eps, 1 - eps] avoids undefined log(0) errors and prevents infinite loss penalties on edge misclassifications.
