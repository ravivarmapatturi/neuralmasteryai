```python
from collections import deque

def simulate_ring_buffer(operations, capacity):
    buf = deque(maxlen=capacity)
    out = []
    for op in operations:
        action = op.get('op')
        if action == 'push':
            buf.append(op.get('val'))
        elif action == 'pop':
            out.append(buf.popleft() if buf else None)
        elif action == 'to_list':
            out.append(list(buf))
    return out
```

Python collections.deque with maxlen manages bounded size in O(1) time per push/pop operation.
