## Overview

Calculate the Gini impurity metric for a set of categorical target labels.

## Task

Implement `gini_impurity(labels)`: compute Gini impurity `1.0 - sum((count_k / N)**2)`. Return 0.0 for empty input. Round float to 4 decimal places.

<Solution>

```python
from collections import Counter

def gini_impurity(labels):
    if not labels:
        return 0.0
    counts = Counter(labels)
    n = len(labels)
    sum_sq = sum((cnt / n) ** 2 for cnt in counts.values())
    return round(float(1.0 - sum_sq), 4)
```

Gini impurity measures the probability of misclassifying a randomly chosen element if randomly labeled according to class distribution.

</Solution>
