```python
import math

def gbm_pseudo_residuals(y_true, raw_predictions, loss_type):
    res = []
    for yt, raw in zip(y_true, raw_predictions):
        if loss_type == 'regression':
            r = yt - raw
        else:
            p = 1.0 / (1.0 + math.exp(-raw)) if raw >= 0 else math.exp(raw) / (1.0 + math.exp(raw))
            r = yt - p
        res.append(round(float(r), 4))
    return res
```

Gradient boosting fits subsequent decision trees to the negative gradient of the loss function, generalising gradient descent to function space.
