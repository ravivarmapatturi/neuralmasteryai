```python
import math

def focal_loss(predictions: list[float], targets: list[int], alpha: float = 0.25, gamma: float = 2.0, eps: float = 1e-7) -> float:
    N = len(predictions)
    losses = []
    for i in range(N):
        p = max(eps, min(1.0 - eps, predictions[i]))
        y = targets[i]
        if y == 1:
            pt = p
            at = alpha
        else:
            pt = 1.0 - p
            at = 1.0 - alpha
        fl = -at * ((1.0 - pt) ** gamma) * math.log(pt)
        losses.append(fl)
    return round(sum(losses) / N, 4)
```

Modulating cross entropy by (1 - p_t)^gamma prevents vast quantities of easy background candidates from overwhelming the training gradients.
