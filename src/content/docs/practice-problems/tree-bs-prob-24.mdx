## Overview

Implement Binary Tree Maximum Path Sum -- one of the most-cited "hard" tree problems, requiring you to track two different quantities at each node: the best path usable by an ancestor (one-sided) vs. the best path through this node (both sides, only valid as a final answer).

## Task

Implement the function `max_path_sum(root)`: a path is any sequence of nodes connected by edges, and does not need to pass through the root or end at a leaf. Return the maximum possible sum of node values along any such path. Node values may be negative.
