```python
def calculate_backoff_delays(base_delay, max_delay, attempts, factor=2.0):
    delays = []
    for i in range(attempts):
        d = min(float(max_delay), float(base_delay) * (float(factor) ** i))
        delays.append(round(d, 2))
    return delays
```

Computing geometric progression capped at max_delay generates predictable and bounded retry schedules.
