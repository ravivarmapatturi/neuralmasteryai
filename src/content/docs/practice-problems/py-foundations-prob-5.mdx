## Overview

Implement `clean_and_tokenize(text)`: normalize raw text by converting to lowercase, stripping punctuation, and breaking it into clean alphanumeric word tokens.

## Task

Implement the function `clean_and_tokenize(text)`: return a list of lowercase alphanumeric word tokens from `text`. Replace any non-alphanumeric non-whitespace characters with spaces before splitting on whitespace. If `text` is empty, return `[]`.

<Solution>

```python
import re

def clean_and_tokenize(text):
    if not text:
        return []
    cleaned = re.sub(r'[^a-zA-Z0-9\s]', ' ', text.lower())
    return cleaned.split()
```

Text cleaning (lowercasing, punctuation removal, whitespace splitting) transforms raw unstructured string input into discrete symbolic tokens for feature extraction.

</Solution>
