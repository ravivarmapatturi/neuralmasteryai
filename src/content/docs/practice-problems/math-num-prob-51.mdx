```python
def conv1d_discrete(signal, kernel, stride=1, padding=0):
    if padding > 0:
        padded = [0.0] * padding + signal + [0.0] * padding
    else:
        padded = list(signal)
    k_len = len(kernel)
    out_len = (len(padded) - k_len) // stride + 1
    out = []
    for i in range(out_len):
        start = i * stride
        val = sum(padded[start + k] * kernel[k] for k in range(k_len))
        out.append(round(float(val), 4))
    return out
```

Pads input array and slides kernel with stride, computing inner products at each valid window.
