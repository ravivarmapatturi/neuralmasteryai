## Overview

Implement `is_palindrome(s)` using the classic two-pointer inward-convergence technique -- scanning from left and right while filtering out punctuation and case differences.

## Task

Implement the function `is_palindrome(s)`: return `True` if `s` is a palindrome (reading the same forwards and backwards after converting all uppercase letters to lowercase and removing all non-alphanumeric characters), or `False` otherwise.
