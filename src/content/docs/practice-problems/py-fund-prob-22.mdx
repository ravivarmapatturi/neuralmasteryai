```python
def string_character_offset_cipher(text, shift):
    res = []
    shift = shift % 26
    for ch in text:
        if ch.isupper():
            res.append(chr((ord(ch) - ord('A') + shift) % 26 + ord('A')))
        elif ch.islower():
            res.append(chr((ord(ch) - ord('a') + shift) % 26 + ord('a')))
        else:
            res.append(ch)
    return "".join(res)
```

Modular arithmetic with base offsets ord("A") and ord("a") wraps characters within their alphabet boundaries.
