## Overview

Implement `three_sum(nums)` to identify all unique zero-sum triplets in O(n^2) time via array sorting and duplicate-skipping two-pointer search.

## Task

Implement the function `three_sum(nums)`: return all unique triplets `[nums[i], nums[j], nums[k]]` such that `nums[i] + nums[j] + nums[k] == 0` without duplicate sets.
