```python
def remove_consecutive_duplicates(items):
    if not items:
        return []
    out = [items[0]]
    for x in items[1:]:
        if x != out[-1]:
            out.append(x)
    return out
```

Checking each incoming item against out[-1] enforces adjacency uniqueness in a single pass.
