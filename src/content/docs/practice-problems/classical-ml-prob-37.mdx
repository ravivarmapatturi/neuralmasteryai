```python
import math

def adaboost_exp_loss(y_true, f_x):
    n = len(y_true)
    if n == 0:
        return 0.0
    total = sum(math.exp(-yt * fx) for yt, fx in zip(y_true, f_x))
    return round(float(total / n), 4)
```

Exponential loss acts as a smooth, convex upper bound on 0-1 misclassification error, heavily penalizing confident wrong predictions.
