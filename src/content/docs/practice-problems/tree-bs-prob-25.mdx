```python
def find_kth_number_multiplication_table(m, n, k):
    lo, hi = 1, m * n
    while lo < hi:
        mid = (lo + hi) // 2
        count = sum(min(mid // i, n) for i in range(1, m + 1))
        if count < k:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

Binary search the product range [1, m * n]. For each candidate mid, count how many products in each row i are `<= mid` using `min(mid // i, n)`. Adjust bounds based on whether `count >= k`.
