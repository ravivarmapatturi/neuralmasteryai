## Overview

Implement `linear_regression_normal_equation(X, y)`, the closed-form (normal equation) solution to ordinary least squares -- the exact solution gradient descent only approximates iteratively, and the textbook baseline every regularized variant (Ridge, Lasso) is a variation of.

## Task

Implement the function `linear_regression_normal_equation(X, y)`: prepend a column of ones to X (for the intercept), then return w = (X_aug^T X_aug)^-1 X_aug^T y as a plain Python list, ordered [intercept, w1, w2, ...]. NumPy is required for the matrix inversion.
