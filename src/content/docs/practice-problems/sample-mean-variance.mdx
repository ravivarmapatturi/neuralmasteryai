**Difficulty: Easy** · Concept: [Probability & Statistics — Expectation, Variance, Covariance](/docs/mathematics-for-ai/probability-statistics#expectation-variance-covariance)

For a dataset $x_1, \dots, x_n$, the mean is $\bar{x} = \frac{1}{n}\sum_i x_i$, and the **population variance** is the average squared deviation from that mean: $\sigma^2 = \frac{1}{n}\sum_i (x_i - \bar{x})^2$. Every summary statistic on this site — standard deviation, standardization/z-scores, the Gaussian assumption behind [MSE](/practice/mean-squared-error) — builds on these two numbers.

**Your task**: implement `sample_mean_and_variance(data)`, returning a `(mean, variance)` tuple. Use the population definition above (divide by $n$, not $n-1$).

```python
def sample_mean_and_variance(data: list[float]) -> tuple[float, float]:
    if not data:
        raise ValueError("data must not be empty")
    n = len(data)
    mean = sum(data) / n
    # Population variance: divide by n, not n - 1.
    variance = sum((x - mean) ** 2 for x in data) / n
    return [round(mean, 6), round(variance, 6)]
```
