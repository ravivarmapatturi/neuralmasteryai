**Difficulty: Easy** · Concept: [Probability & Statistics — Expectation, Variance, Covariance](/docs/mathematics-for-ai/probability-statistics#expectation-variance-covariance)

For a dataset $x_1, \dots, x_n$, the mean is $\bar{x} = \frac{1}{n}\sum_i x_i$, and the **population variance** is the average squared deviation from that mean: $\sigma^2 = \frac{1}{n}\sum_i (x_i - \bar{x})^2$. Every summary statistic on this site — standard deviation, standardization/z-scores, the Gaussian assumption behind [MSE](/practice/mean-squared-error) — builds on these two numbers.

**Your task**: implement `sample_mean_and_variance(data)`, returning a `(mean, variance)` tuple. Use the population definition above (divide by $n$, not $n-1$).

<Solution>

```python
def sample_mean_and_variance(data):
    n = len(data)
    mean = sum(data) / n
    variance = sum((x - mean) ** 2 for x in data) / n
    return mean, variance
```

Two passes over the data, each a direct transcription of a formula: the mean needs to be known before any deviation can be measured, so it has to be computed first and can't be folded into the same pass as the variance sum. `[1, 1, 1, 1]` and `[10]` both correctly give variance `0.0` — no spread at all when every value is identical (or there's only one value), exactly what "average squared deviation from the mean" should produce.

One thing worth knowing even though it isn't tested here: NumPy's `np.var` also defaults to this population form (`ddof=0`), but `pandas`' `.var()` defaults to the **sample** variance instead (divide by $n-1$, Bessel's correction — an unbiased estimator of the *population* variance when your data is itself a random sample from some larger population). Mixing the two up silently is a real, easy-to-make bug when moving between NumPy and pandas code.
