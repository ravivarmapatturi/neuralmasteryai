Filter duplicate streaming event IDs within a sliding time-to-live expiration window. Prerequisite: `numpy-pandas-prob-14`.

<Solution>

```python
def sliding_window_dedupe(events, ttl):
    if not events or ttl <= 0:
        return []
    last_seen = {}
    accepted = []
    for ev in events:
        eid = ev["id"]
        ts = ev["timestamp"]
        if eid not in last_seen or (ts - last_seen[eid]) > ttl:
            accepted.append(eid)
            last_seen[eid] = ts
    return accepted
```

Sliding TTL tracking maintains event liveness in an eviction hash map, dropping duplicate messages arriving within the retry envelope while permitting legitimate recurrences after timeout.
