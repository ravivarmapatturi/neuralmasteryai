## Overview

Compute nearest squared centroid distances for K-Means++ probabilistic initialization.

## Task

Implement `kmeans_plus_plus_distances(points, centroids)`: for each point `x`, find `min(sum((x[j] - c[j])**2 for c in centroids))`. Return list of minimum squared distances rounded to 4 decimal places.

<Solution>

```python
def kmeans_plus_plus_distances(points, centroids):
    d_sq_list = []
    for pt in points:
        min_d_sq = min(sum((x - c) ** 2 for x, c in zip(pt, cent)) for cent in centroids)
        d_sq_list.append(round(float(min_d_sq), 4))
    return d_sq_list
```

K-Means++ selects subsequent centroids with probability proportional to D(x)^2, ensuring well-spread initial centers and bounding expected error.

</Solution>
