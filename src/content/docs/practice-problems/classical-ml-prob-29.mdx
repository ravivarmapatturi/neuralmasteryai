```python
def perceptron_step(x, y, weights, bias, lr):
    act = sum(w * a for w, a in zip(weights, x)) + bias
    if y * act <= 0.0:
        new_w = [round(w + lr * y * a, 4) for w, a in zip(weights, x)]
        new_b = round(bias + lr * y, 4)
        updated = True
    else:
        new_w = [round(w, 4) for w in weights]
        new_b = round(bias, 4)
        updated = False
    return {"weights": new_w, "bias": new_b, "updated": updated}
```

Perceptron learning updates parameters only when an error occurs, rotating the decision hyperplane toward the misclassified sample.
