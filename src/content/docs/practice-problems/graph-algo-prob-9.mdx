```python
def all_paths_source_target(graph):
    target = len(graph) - 1
    res = []
    def dfs(curr, path):
        if curr == target:
            res.append(list(path))
            return
        for nbr in graph[curr]:
            path.append(nbr)
            dfs(nbr, path)
            path.pop()
    dfs(0, [0])
    return res
```

Recurse along directed edges starting from node 0. When the destination node is reached, capture a copy of the path.
