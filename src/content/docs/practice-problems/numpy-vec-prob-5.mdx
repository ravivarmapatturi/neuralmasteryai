```python
import math

def mahalanobis_distance(u, v, inv_cov):
    diff = [a - b for a, b in zip(u, v)]
    d = len(diff)
    temp = [sum(diff[j] * inv_cov[j][i] for j in range(d)) for i in range(d)]
    dist_sq = sum(temp[i] * diff[i] for i in range(d))
    return round(float(math.sqrt(max(0.0, dist_sq))), 4)
```

Calculates the quadratic form of the difference vector with the precision matrix and takes square root.
