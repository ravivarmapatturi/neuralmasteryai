```python
def top_k_frequent(items, k):
    if k < 0:
        raise ValueError('k cannot be negative')
    if not items:
        if k == 0:
            return []
        raise ValueError('k exceeds number of unique elements')
    freq = {}
    for x in items:
        freq[x] = freq.get(x, 0) + 1
    if k > len(freq):
        raise ValueError('k exceeds number of unique elements')
    sorted_items = sorted(freq.keys(), key=lambda x: (-freq[x], str(x)))
    return sorted_items[:k]
```

Filtering datasets down to top-K frequent categories or tokens prevents high-cardinality explosion and prunes long-tail noise in ML pipelines.
