```python
import math

def directional_derivative(grad, direction):
    norm_v = math.sqrt(sum(d ** 2 for d in direction))
    if norm_v < 1e-9:
        return 0.0
    u = [d / norm_v for d in direction]
    val = sum(g * d for g, d in zip(grad, u))
    return round(float(val), 4)
```

Normalizes search vector to unit length and takes dot product with gradient.
