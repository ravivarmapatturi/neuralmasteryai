```python
def bayes_posterior(priors, likelihoods):
    unnorm = [p * l for p, l in zip(priors, likelihoods)]
    total = sum(unnorm)
    if total < 1e-12:
        return [1.0 / len(priors)] * len(priors)
    post = [round(float(u / total), 4) for u in unnorm]
    return post
```

Calculates unnormalized joint probabilities and divides by the marginal evidence sum.
