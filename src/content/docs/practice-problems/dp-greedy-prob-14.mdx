## Overview

Find the length of the longest subsequence shared between two text sequences using 2D DP.

## Task

Implement `longest_common_subsequence(text1, text2)`: if text1[i] == text2[j], dp[j] = prev + 1; otherwise dp[j] = max(dp[j], dp[j-1]).

<Solution>

```python
def longest_common_subsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [0] * (n + 1)
    for c1 in text1:
        prev = 0
        for j, c2 in enumerate(text2, 1):
            temp = dp[j]
            if c1 == c2:
                dp[j] = prev + 1
            else:
                dp[j] = max(dp[j], dp[j - 1])
            prev = temp
    return dp[n]
```

Iterate through characters of text1 and text2. Matching characters increment the diagonal subproblem result; mismatches take the max of discarding from either text.
