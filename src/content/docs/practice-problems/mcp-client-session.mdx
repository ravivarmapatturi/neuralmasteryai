**Difficulty: Medium** · Topic: Agents & Applications · Concept: [Model Context Protocol (MCP)](/docs/agents/mcp/overview)

Before an MCP Client can request tools or resources from an MCP Server, it must perform the protocol handshake by sending an `initialize` request and handling the server's response. Implement `mcp_client_initialize(client_info, protocol_version)` that creates the initialization request and processes the server response to extract supported capabilities (tools, resources, prompts).

<Solution>

```python
import json

def mcp_client_initialize(client_info, protocol_version="2024-11-05"):
    """
    Constructs the standard MCP JSON-RPC 2.0 initialization request payload.
    """
    return json.dumps({
        "jsonrpc": "2.0",
        "id": 1,
        "method": "initialize",
        "params": {
            "protocolVersion": protocol_version,
            "capabilities": {
                "roots": {"listChanged": True},
                "sampling": {}
            },
            "clientInfo": client_info
        }
    })

def parse_server_capabilities(response_json_str):
    """
    Parses MCP server initialize response and returns set of active capabilities.
    """
    res = json.loads(response_json_str)
    result = res.get("result", {})
    capabilities = result.get("capabilities", {})
    
    active = []
    if "tools" in capabilities:
        active.append("tools")
    if "resources" in capabilities:
        active.append("resources")
    if "prompts" in capabilities:
        active.append("prompts")
    if "logging" in capabilities:
        active.append("logging")
        
    return {
        "protocolVersion": result.get("protocolVersion"),
        "serverInfo": result.get("serverInfo", {}),
        "capabilities": active
    }
```

The MCP initialization sequence guarantees compatibility between Host clients and external Servers. The client transmits its name, version, and client capabilities, while the server responds with its negotiated protocol version and supported features before any tool execution begins.
