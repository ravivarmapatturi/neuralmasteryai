Standardize feature distributions to zero mean and unit variance using vectorized NumPy operations. Prerequisite: `numpy-pandas-prob-3`.

<Solution>

```python
import numpy as np

def z_score_standardize(values):
    if not values:
        return []
    arr = np.array(values, dtype=float)
    mean = float(np.mean(arr))
    std = float(np.std(arr, ddof=0))
    if std == 0.0:
        return [0.0] * len(values)
    z = (arr - mean) / std
    return [round(float(x), 4) for x in z]
```

Z-score transformation normalizes feature scales across heterogeneous metrics, allowing gradient optimizers to converge along symmetric contours.

</Solution>
