**Difficulty: Medium** · Concept: [Training Pipeline — Parameter-Efficient Fine-Tuning (PEFT)](/docs/llms-genai/training-pipeline#parameter-efficient-fine-tuning-peft)

$$y = xW_0^\top + \frac{\alpha}{r}\,(xA^\top)B^\top$$

Full fine-tuning updates every weight in a pretrained model — expensive in both compute and storage (a full copy of every weight per fine-tuned variant). LoRA instead freezes the original weight matrix $W_0$ entirely and learns a much smaller *low-rank* update: two small matrices $A$ (rank $r$) and $B$, where $r$ is far smaller than the original dimensions, added back in at inference time as $\frac{\alpha}{r}\,(xA^\top)B^\top$. Only $A$ and $B$ need training and storage — often under 1% of the original parameter count — which is exactly why LoRA is the standard way most LLM fine-tuning happens today.

**Your task**: implement `lora_linear(x, W0, A, B, alpha, r)` where `x` is `(batch, in_features)`, `W0` is `(out_features, in_features)` (the frozen base weight), `A` is `(r, in_features)`, and `B` is `(out_features, r)`.
