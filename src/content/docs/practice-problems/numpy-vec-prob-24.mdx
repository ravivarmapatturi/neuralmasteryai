## Overview

Prevent autoregressive models from attending to future sequence tokens via upper-triangular masking.

## Task

Implement `apply_causal_mask(scores, mask_val)`: for a square attention score matrix `scores` of shape `(S, S)`, replace all upper-triangular elements `scores[i][j]` where `j > i` with `mask_val`. Keep elements where `j <= i` intact. Round all elements to 4 decimals.

<Solution>

```python
def apply_causal_mask(scores, mask_val=-10000.0):
    S = len(scores)
    return [[round(float(mask_val), 4) if j > i else round(float(scores[i][j]), 4) for j in range(S)] for i in range(S)]
```

Substitutes mask_val at indices where column index exceeds row index.

</Solution>
