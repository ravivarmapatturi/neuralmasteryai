```python
def apply_causal_mask(scores, mask_val=-10000.0):
    S = len(scores)
    return [[round(float(mask_val), 4) if j > i else round(float(scores[i][j]), 4) for j in range(S)] for i in range(S)]
```

Substitutes mask_val at indices where column index exceeds row index.
