## Overview

Compute the fundamental affine transformation for a fully connected (dense) neural network layer across a mini-batch.

## Task

Implement `dense_forward(x, w, b)` which computes the forward pass of a linear layer: `y = x @ w + b`. Given `x` of shape `(N, D_in)`, weight matrix `w` of shape `(D_in, D_out)`, and bias vector `b` of length `D_out`, return the output matrix of shape `(N, D_out)` where each element is rounded to 4 decimal places.

<Solution>

```python
def dense_forward(x: list[list[float]], w: list[list[float]], b: list[float]) -> list[list[float]]:
    N = len(x)
    D_in = len(w)
    D_out = len(w[0])
    out = []
    for i in range(N):
        row = []
        for j in range(D_out):
            val = sum(x[i][k] * w[k][j] for k in range(D_in)) + b[j]
            row.append(round(float(val), 4))
        out.append(row)
    return out
```

For each batch sample, compute the matrix product with weights `w` and add the broadcasted bias `b`. Round each resulting value to 4 decimal places.

</Solution>
