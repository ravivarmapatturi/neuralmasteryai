Compute the running maximum over a bounded sliding capacity window on a streaming signal. Prerequisite: `numpy-pandas-prob-11`.

<Solution>

```python
from collections import deque

def streaming_sliding_max(stream, window_size):
    if not stream or window_size <= 0:
        return []
    res = []
    dq = deque()
    for i, x in enumerate(stream):
        while dq and dq[0] <= i - window_size:
            dq.popleft()
        while dq and stream[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        res.append(stream[dq[0]])
    return res
```

A monotonic double-ended queue maintains candidate maxima in decreasing order, evicting expired indices from the head and dominated candidates from the tail in amortized O(1) time.
