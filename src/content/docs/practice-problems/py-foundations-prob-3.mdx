```python
def invert_dictionary(mapping):
    inv = {}
    for k, v in mapping.items():
        if v not in inv:
            inv[v] = []
        inv[v].append(k)
    for v in inv:
        inv[v].sort()
    return inv
```

Inverting mappings to create multi-value lookups is the cornerstone of search engines (inverted index: term -> doc IDs) and clustering groupings.
