## Overview

Implement Content-Length-prefixed message framing parsing, the real wire format MCP's stdio transport uses (identical in shape to LSP's framing).

## Task

Implement `parse_stdio_frame(raw_bytes)`. The format is a header line `'Content-Length: N\r\n'`, a blank line `'\r\n'`, then exactly N bytes of body. Parse `N` from the header, extract the body of that exact length, and return `(body, remainder)` where `remainder` is whatever bytes come after the frame (may be `''`).
