**Difficulty: Medium** · Topic: Deep Learning

Implement the self-normalizing SELU activation function with exact scale (lambda) and alpha constants.

<Solution>

```python
import math

def selu(x, scale=1.0507009873554805, alpha=1.6732632423543772):
    return [scale * val if val > 0 else scale * alpha * (math.exp(val) - 1.0) for val in x]
```

SELU enables self-normalizing neural networks where activations converge toward zero mean and unit variance without explicit BatchNorm layers.

</Solution>
