```python
def deserialize_tree(data):
    tokens = iter(data.split(','))
    def helper():
        val = next(tokens, None)
        if val is None or val == '#':
            return None
        node = {'val': int(val), 'left': None, 'right': None}
        node['left'] = helper()
        node['right'] = helper()
        return node
    return helper()
```

Iterate through tokens. In preorder order, the first token is the root; its left subtree consumes tokens until it completes, after which the right subtree consumes its tokens.
