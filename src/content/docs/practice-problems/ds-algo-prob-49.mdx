```python
def word_break_ii(s, word_dict):
    word_set = set(word_dict)
    memo = {}

    def dp(start):
        if start in memo:
            return memo[start]
        if start == len(s):
            return [[]]
        results = []
        for end in range(start + 1, len(s) + 1):
            word = s[start:end]
            if word in word_set:
                for rest in dp(end):
                    results.append([word] + rest)
        memo[start] = results
        return results

    return [' '.join(path) for path in dp(0)]
```

Top-down DP: memo[start] = all valid segmentation lists from position start. The memoization avoids exponential recomputation. Output construction can still be large. O(n^2 * 2^n) worst case.
