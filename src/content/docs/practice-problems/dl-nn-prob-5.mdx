## Overview

Compute the analytical gradient of Mean Squared Error loss w.r.t network predictions to initiate backpropagation.

## Task

Implement `mse_loss_backward(y_pred, y_true)`: with `MSE = (1 / (N * D)) * sum((y_pred - y_true)^2)`, compute the derivative with respect to each prediction `y_pred[i][j]`, which is `(2 / (N * D)) * (y_pred[i][j] - y_true[i][j])`. Here `N` is the number of rows and `D` is the number of columns. Round each gradient element to 4 decimal places.

<Solution>

```python
def mse_loss_backward(y_pred: list[list[float]], y_true: list[list[float]]) -> list[list[float]]:
    N = len(y_pred)
    D = len(y_pred[0])
    total_elements = N * D
    grad = []
    for i in range(N):
        row = []
        for j in range(D):
            val = (2.0 / total_elements) * (y_pred[i][j] - y_true[i][j])
            row.append(round(float(val), 4))
        grad.append(row)
    return grad
```

Differentiating (1/M) sum (y_hat - y)^2 w.r.t y_hat yields (2/M)(y_hat - y) where M = N * D is the total number of evaluated scalar predictions.
