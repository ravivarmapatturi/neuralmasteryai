```python
def num_distinct_subsequences(s, t):
    m, n = len(s), len(t)
    dp = [0] * (n + 1)
    dp[0] = 1
    for c_s in s:
        for j in range(n, 0, -1):
            if c_s == t[j - 1]:
                dp[j] += dp[j - 1]
    return dp[n]
```

Maintain a 1D DP table representing prefix matches of t. When character c_s in s matches t[j-1], add the number of valid prefixes up to j-1.
