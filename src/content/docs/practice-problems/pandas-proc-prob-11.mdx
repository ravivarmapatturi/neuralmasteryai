```python
from collections import defaultdict

def unstack_multilevel_index(rows):
    res = defaultdict(lambda: defaultdict(dict))
    for entity, date, metric, val in rows:
        res[entity][date][metric] = round(float(val), 4)
    return {k: {dk: dict(dv) for dk, dv in v.items()} for k, v in sorted(res.items())}
```

Pivots long relational multi-index tuples into a nested dictionary.
