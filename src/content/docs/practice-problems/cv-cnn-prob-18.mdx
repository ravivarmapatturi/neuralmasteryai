```python
import math

def spatial_pyramid_pooling(feature_map: list[list[float]], pool_sizes: list[int]) -> list[float]:
    H = len(feature_map)
    W = len(feature_map[0])
    result = []
    for n in pool_sizes:
        for bi in range(n):
            r_start = math.floor(bi * H / n)
            r_end = math.ceil((bi + 1) * H / n)
            for bj in range(n):
                c_start = math.floor(bj * W / n)
                c_end = math.ceil((bj + 1) * W / n)
                max_val = max(feature_map[r][c] for r in range(r_start, r_end) for c in range(c_start, c_end))
                result.append(round(float(max_val), 4))
    return result
```

Partitioning the arbitrary HxW map into n-by-n bins and computing maximums creates a deterministic feature vector size regardless of input dimension.
