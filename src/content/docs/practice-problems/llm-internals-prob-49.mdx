## Overview

Implement LoRA adapter merging, the real formula for folding a trained low-rank adapter back into the base model weight for zero-overhead inference.

## Task

Implement `merge_lora(base_weight, lora_a, lora_b, alpha, rank)` (simplified to scalars representing one weight element's low-rank update): return `base_weight + (alpha/rank) * lora_a * lora_b`.
