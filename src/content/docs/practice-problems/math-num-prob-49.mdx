```python
def kalman_filter_step(x_prior, P_prior, measurement, H=1.0, R=1.0):
    y = measurement - H * x_prior
    S = H * P_prior * H + R
    K = (P_prior * H) / S
    x_post = x_prior + K * y
    P_post = (1.0 - K * H) * P_prior
    return {'x_post': round(float(x_post), 4), 'P_post': round(float(P_post), 4), 'K': round(float(K), 4)}
```

Updates mean and variance via minimum-variance fusion of prior belief and sensor observation.
