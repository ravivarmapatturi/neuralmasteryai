```python
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []
```

Using a hash map allows looking up the required complement `target - num` in O(1) expected time, achieving overall O(n) runtime and O(n) auxiliary space.
