**Track**: Dynamic Programming & Greedy | **Rank**: #657 of 1072 | **Points**

## Overview

Simulate cash register change-making greedily prioritizing larger denomination bills to preserve change flexibility.

## Task

Implement `lemonade_change(bills)`: track counts of \$5 and \$10 bills. When receiving a \$20, greedily give one \$10 and one \$5 as change (saving \$5 bills for subsequent change).

<PracticePlayground problemId="dp-greedy-prob-7" />

<Solution>

```python
def lemonade_change(bills):
    five = 0
    ten = 0
    for bill in bills:
        if bill == 5:
            five += 1
        elif bill == 10:
            if five == 0:
                return False
            five -= 1
            ten += 1
        else:
            if ten > 0 and five > 0:
                ten -= 1
                five -= 1
            elif five >= 3:
                five -= 3
            else:
                return False
    return True
```

Track counts of \$5 and \$10 bills. When giving \$15 in change for a \$20 bill, prefer using one \$10 and one \$5 to conserve the highly versatile \$5 bills.
