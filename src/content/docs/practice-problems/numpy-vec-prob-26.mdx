```python
def low_rank_svd_reconstruct(U, S, Vt, rank_k):
    M, N = len(U), len(Vt[0])
    res = [[0.0 for _ in range(N)] for _ in range(M)]
    for idx in range(rank_k):
        s = S[idx]
        for i in range(M):
            u = U[i][idx]
            for j in range(N):
                res[i][j] += s * u * Vt[idx][j]
    return [[round(float(v), 4) for v in row] for row in res]
```

Accumulates the first rank_k outer product rank-1 matrices scaled by their singular values.
