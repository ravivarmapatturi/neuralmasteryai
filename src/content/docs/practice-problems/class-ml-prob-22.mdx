```python
import math

def softmax_probabilities(logits):
    res = []
    for row in logits:
        max_v = max(row)
        exps = [math.exp(v - max_v) for v in row]
        sum_exp = sum(exps)
        res.append([round(e / sum_exp, 4) for e in exps])
    return res
```

Subtract row maximums to avoid numerical overflow, exponentiate, and divide by the row sum to form normalized probability distributions.
