## Overview

Implement `longest_consecutive(nums)` via the O(n) hash-set solution -- the classic case where sorting FEELS natural but is the wrong complexity, and a hash set achieves true O(n).

## Task

Implement the function `longest_consecutive(nums)`: return the length of the longest run of consecutive integers present in `nums` (in any order in the input). Must run in O(n) time (no sorting).
