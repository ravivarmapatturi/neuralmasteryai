## Overview

Implement sign-based binary quantization, a cheap first-pass filter real vector databases use before exact re-ranking.

## Task

Implement `binary_quantize_hamming(a, b)`. Quantize each vector to a bit per dimension (`1` if the component is `>= 0`, else `0`), then return the Hamming distance (count of differing bits) between the two quantized vectors.
