## Overview

Split an input hidden representation vector into multiple distinct attention heads. Multi-Head Attention allows the transformer to attend jointly to information from different representation subspaces at different positions.

## Task

Implement `split_heads(x, num_heads)`: divide a 1D vector `x` of dimension `d_model` into `num_heads` contiguous sub-vectors, each of dimension `d_head = len(x) // num_heads`. If `len(x) % num_heads != 0` or `num_heads <= 0` or `not x`, raise `ValueError`.
