## Overview

Implement `brute_force_knn(query, vectors, k)`, the exact ('flat') k-nearest-neighbor search that every approximate nearest-neighbor (ANN) index -- HNSW, IVF, LSH -- is an approximation of. It's the ground-truth baseline used to measure the recall of every faster index structure.

## Task

Implement the function `brute_force_knn(query, vectors, k)`: compute the Euclidean distance from `query` to every row in `vectors`, and return the indices of the `k` nearest, ordered nearest-first with ties broken by ascending index. Raise `ValueError` if `k <= 0` or `k > len(vectors)`.
