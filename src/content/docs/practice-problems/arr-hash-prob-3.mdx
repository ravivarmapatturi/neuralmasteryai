## Overview

Implement `is_anagram(s, t)`, anagram detection via character-frequency counting -- the general hash-map pattern for "do two collections hold the exact same multiset of items?"

## Task

Implement the function `is_anagram(s, t)`, returning `True` if `t` is an anagram of `s` (same characters, same multiplicity, any order), `False` otherwise.
