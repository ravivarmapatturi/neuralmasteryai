```python
def find_cheapest_price(n, flights, src, dst, k):
    prices = [float('inf')] * n
    prices[src] = 0
    for _ in range(k + 1):
        tmp = prices[:]
        for u, v, price in flights:
            if prices[u] != float('inf') and prices[u] + price < tmp[v]:
                tmp[v] = prices[u] + price
        prices = tmp
    return prices[dst] if prices[dst] != float('inf') else -1
```

Bellman-Ford limited to k+1 relaxation rounds (k stops = k+1 edges). Snapshot `prices` before each round to prevent using more than one new edge per round. O(k * E) time.
