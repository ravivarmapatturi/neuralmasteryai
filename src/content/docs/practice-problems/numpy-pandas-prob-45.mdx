```python
def schedule_stream_retries(attempts, base_delay, factor, max_delay):
    out = []
    for att in attempts:
        if att <= 0:
            out.append(0.0)
        else:
            delay = min(max_delay, base_delay * (factor ** (att - 1)))
            out.append(round(float(delay), 4))
    return out
```

Exponential backoff dampens traffic floods during downstream service degradation by exponentially spacing retransmission requests.
