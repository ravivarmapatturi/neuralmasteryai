```python
def find_peak_element(nums):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < nums[mid + 1]:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

By comparing nums[mid] with nums[mid + 1], we determine whether the local slope rises or falls. Walking uphill is guaranteed to terminate at a peak.
