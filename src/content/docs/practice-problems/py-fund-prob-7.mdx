```python
def dict_invert_multi(d):
    inv = {}
    for k, v in d.items():
        inv.setdefault(v, []).append(k)
    return {k: sorted(v) for k, v in sorted(inv.items())}
```

Grouping by value and sorting inner lists produces a canonical multi-value inverted map.
