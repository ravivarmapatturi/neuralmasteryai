## Overview

Enforce generation termination boundaries by cutting completed or streamed text at the earliest occurrence of stop tokens. In production LLM application engineering, reliable system components, deterministic interfaces, and defensive validation are paramount for production stability and cost efficiency.

## Task

Implement `apply_stop_sequences(text, stop_sequences)`. Find the earliest index in `text` where any non-empty sequence from `stop_sequences` appears. If found, truncate `text` immediately before the sequence, set `stopped: True`, and record `matched_sequence`. If none found or `stop_sequences` is empty, return original text with `stopped: False` and `matched_sequence: None`.
