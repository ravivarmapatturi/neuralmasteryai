```python
import math

def adaboost_weight_update(weights, y_true, y_pred, alpha):
    new_weights = [w * math.exp(-alpha * yt * yp) for w, yt, yp in zip(weights, y_true, y_pred)]
    total = sum(new_weights)
    return [round(w / total, 4) for w in new_weights]
```

Multiply weights by exp(-alpha * y * y_hat), which scales up misclassified instances and scales down correctly predicted instances, followed by normalization.
