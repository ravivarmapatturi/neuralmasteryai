```python
from collections import defaultdict

def cumulative_metrics_by_group(records, group_key, val_key):
    group_sum = defaultdict(float)
    group_max = defaultdict(lambda: float('-inf'))
    out = []
    for r in records:
        grp = r[group_key]
        v = r[val_key]
        group_sum[grp] += v
        if v > group_max[grp]:
            group_max[grp] = v
        copy_r = dict(r)
        copy_r["cum_sum"] = round(group_sum[grp], 4)
        copy_r["cum_max"] = round(group_max[grp], 4)
        out.append(copy_r)
    return out
```

Partitioned cumulative aggregates maintain separate running states per group key, analogous to SQL window functions over partitioned series.
