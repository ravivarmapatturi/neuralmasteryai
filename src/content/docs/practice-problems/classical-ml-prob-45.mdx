```python
def elastic_net_penalty(weights, l1_ratio, alpha):
    l1 = sum(abs(w) for w in weights)
    l2_sq = sum(w ** 2 for w in weights)
    val = alpha * (l1_ratio * l1 + 0.5 * (1.0 - l1_ratio) * l2_sq)
    return round(float(val), 4)
```

Elastic Net combines L1 feature sparsity with L2 grouped feature selection, overcoming Lassos limitation when features are highly correlated.
