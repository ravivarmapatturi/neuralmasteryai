```python
def lowest_common_ancestor_bt(root, p, q):
    def dfs(node):
        if not node:
            return None
        if node['val'] == p or node['val'] == q:
            return node
        left = dfs(node.get('left'))
        right = dfs(node.get('right'))
        if left and right:
            return node
        return left if left else right
    res = dfs(root)
    return res['val'] if res else -1
```

Recursively search both subtrees. If both return a target, the current node is their convergence point (the LCA). Otherwise, propagate up whichever target was found.
