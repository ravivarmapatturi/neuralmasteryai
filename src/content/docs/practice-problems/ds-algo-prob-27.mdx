```python
from collections import deque

def right_side_view(root):
    if not root:
        return []
    result = []
    q = deque([root])
    while q:
        n = len(q)
        for i in range(n):
            node = q.popleft()
            if i == n - 1:
                result.append(node['val'])
            if node['left']:
                q.append(node['left'])
            if node['right']:
                q.append(node['right'])
    return result
```

Level-order BFS; the last node dequeued at each level is the rightmost. Record it with `if i == n-1`. O(n) time.
