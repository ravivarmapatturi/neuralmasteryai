## Overview

Implement `find_median_sorted_arrays(nums1, nums2)`, the binary-search-on-partition-point solution -- one of the most-cited "hard" interview problems, solved by binary searching for a partition rather than ever merging the two arrays.

## Task

Implement the function `find_median_sorted_arrays(nums1, nums2)`: both arrays are already sorted ascending. Return the median of the combined (conceptually merged) sorted array, as a float, in O(log(min(len(nums1), len(nums2)))) time.
