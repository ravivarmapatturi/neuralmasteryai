Compute the rolling moving average across a sliding window of data stream values. Prerequisite: `numpy-pandas-prob-2`.

<Solution>

```python
import numpy as np

def rolling_moving_average(values, window_size):
    if not values or window_size <= 0 or len(values) < window_size:
        return []
    arr = np.array(values, dtype=float)
    weights = np.ones(window_size) / window_size
    sma = np.convolve(arr, weights, mode='valid')
    return [round(float(x), 4) for x in sma]
```

Convolution of the input signal with a uniform boxcar kernel computes the exact unweighted moving average for all valid overlapping positions in a single vectorized pass.
