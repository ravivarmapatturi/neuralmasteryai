## Overview

Implement `build_inverted_index(documents)`, the classic sparse-retrieval data structure used by BM25, Elasticsearch, and hybrid search systems -- the structure a production dense vector index is typically paired with for keyword-aware RAG retrieval.

## Task

Implement the function `build_inverted_index(documents)`, where `documents` is a list of already-tokenized documents (each a list of string tokens). Return a `dict` mapping each unique token to the sorted, de-duplicated list of document indices in which it appears.
