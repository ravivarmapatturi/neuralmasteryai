**Difficulty: Easy** · Concept: [Loss Functions — Classification Losses](/docs/deep-learning/loss-functions#classification-losses)

$$\mathcal{L} = -\frac{1}{N}\sum_{n=1}^{N} \log p_n[y_n]$$

Categorical cross-entropy measures how much probability a model's softmax output assigns to the *correct* class — the lower the probability given to the true label, the higher the loss, with a genuinely unbounded penalty as that probability approaches 0. This is the loss behind every multi-class classifier, and it's exactly what trains an LLM's next-token prediction: each token in a sequence is one classification decision over the whole vocabulary.
