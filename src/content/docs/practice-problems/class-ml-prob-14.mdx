## Overview

Implement `gaussian_naive_bayes_predict(X_train, y_train, x_test)`, Gaussian Naive Bayes end to end -- parameter estimation (per-class means/variances) AND MAP prediction (log-prior plus log-likelihood, maximized over classes).

## Task

Implement the function `gaussian_naive_bayes_predict(X_train, y_train, x_test)`: for each class, estimate its prior and a per-feature Gaussian (mean, variance) from the training rows of that class, then predict the class with the highest log(prior) + sum(log Gaussian pdf) for x_test. Add 1e-9 to every variance to avoid division by zero.
