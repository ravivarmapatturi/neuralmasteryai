```python
import bisect

def empirical_cdf(samples, query_points):
    if not samples:
        return [0.0] * len(query_points)
    n = len(samples)
    sorted_s = sorted(samples)
    out = []
    for q in query_points:
        count = bisect.bisect_right(sorted_s, q)
        out.append(round(count / n, 4))
    return out
```

The empirical CDF converges uniformly to the true underlying CDF by the Glivenko-Cantelli theorem, providing non-parametric quantile estimation.
