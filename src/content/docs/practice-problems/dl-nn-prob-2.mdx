```python
def relu_backward(dout: list[list[float]], x: list[list[float]]) -> list[list[float]]:
    out = []
    for i in range(len(dout)):
        row = []
        for j in range(len(dout[0])):
            grad = dout[i][j] if x[i][j] > 0.0 else 0.0
            row.append(round(float(grad), 4))
        out.append(row)
    return out
```

The derivative of ReLU(x) is 1 for x `>` 0 and 0 for x `<=` 0. By the chain rule, upstream gradient dout is multiplied element-wise by this local derivative.
