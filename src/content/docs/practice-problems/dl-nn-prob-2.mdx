## Overview

Backpropagate upstream gradients through a Rectified Linear Unit (ReLU) activation function.

## Task

Implement `relu_backward(dout, x)` which computes the element-wise gradient `dx` given upstream gradient `dout` and forward input cache `x`. For each element, if `x[i][j] > 0`, the derivative is 1 so `dx[i][j] = dout[i][j]`; if `x[i][j] <= 0`, the derivative is 0 so `dx[i][j] = 0.0`. Round results to 4 decimal places.

<Solution>

```python
def relu_backward(dout: list[list[float]], x: list[list[float]]) -> list[list[float]]:
    out = []
    for i in range(len(dout)):
        row = []
        for j in range(len(dout[0])):
            grad = dout[i][j] if x[i][j] > 0.0 else 0.0
            row.append(round(float(grad), 4))
        out.append(row)
    return out
```

The derivative of ReLU(x) is 1 for x `>` 0 and 0 for x `<=` 0. By the chain rule, upstream gradient dout is multiplied element-wise by this local derivative.

</Solution>
