```python
def nested_key_counter(data):
    count = 0
    def walk(obj):
        nonlocal count
        if isinstance(obj, dict):
            for k, v in obj.items():
                count += 1
                walk(v)
        elif isinstance(obj, list):
            for item in obj:
                walk(item)
    walk(data)
    return count
```

Recursively inspecting dicts and lists traverses all JSON tree nodes in linear time.
