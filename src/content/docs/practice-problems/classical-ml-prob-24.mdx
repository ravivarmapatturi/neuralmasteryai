```python
import math

def davies_bouldin_pair(centroid_i, spread_i, centroid_j, spread_j):
    dist = math.sqrt(sum((x - y) ** 2 for x, y in zip(centroid_i, centroid_j)))
    if dist == 0.0:
        return 0.0
    val = (spread_i + spread_j) / dist
    return round(float(val), 4)
```

Davies-Bouldin compares intra-cluster spread against inter-cluster centroid separation; lower values indicate superior clustering quality.
