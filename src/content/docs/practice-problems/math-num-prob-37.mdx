```python
def finite_difference_gradient(f_center, f_plus, f_minus, h=0.0001):
    grad = [(fp - fm) / (2.0 * h) for fp, fm in zip(f_plus, f_minus)]
    return [round(float(g), 4) for g in grad]
```

Evaluates O(h^2) symmetric quotient for each coordinate axis.
