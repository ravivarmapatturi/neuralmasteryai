```python
import math

def knn_regression_predict(x_train, y_train, x_query, k):
    distances = []
    for xt, yt in zip(x_train, y_train):
        d = math.sqrt(sum((a - b) ** 2 for a, b in zip(xt, x_query)))
        distances.append((d, yt))
    distances.sort(key=lambda x: x[0])
    top_k = distances[:k]
    avg = sum(yt for _, yt in top_k) / k if k > 0 else 0.0
    return round(float(avg), 4)
```

KNN regression provides non-parametric local estimation, approximating the conditional expectation E[Y | X=x] via neighbor averaging.
