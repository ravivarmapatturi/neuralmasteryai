```python
def armijo_line_search(f_curr, grad_norm_sq, candidate_evals, alpha=1.0, beta=0.5, c=1e-4):
    curr_alpha = alpha
    for f_step in candidate_evals:
        if f_step <= f_curr - c * curr_alpha * grad_norm_sq:
            return round(float(curr_alpha), 4)
        curr_alpha *= beta
    return round(float(curr_alpha), 4)
```

Iteratively shrinks step size until objective decrease exceeds linear threshold fraction.
