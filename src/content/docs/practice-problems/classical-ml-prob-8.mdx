```python
def user_jaccard_similarity(user_a_items, user_b_items):
    sa = set(user_a_items)
    sb = set(user_b_items)
    union = sa | sb
    if not union:
        return 1.0
    inter = sa & sb
    return round(len(inter) / len(union), 6)
```

Jaccard similarity measures overlap of implicit binary feedback (clicks, purchases, views) without needing explicit rating scales.
