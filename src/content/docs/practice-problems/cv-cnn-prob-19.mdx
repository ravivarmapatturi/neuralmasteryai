```python
def mixup_blend(img1: list[list[float]], img2: list[list[float]], label1: list[float], label2: list[float], lam: float) -> dict:
    H = len(img1)
    W = len(img1[0])
    mixed_img = []
    for i in range(H):
        row = []
        for j in range(W):
            val = lam * img1[i][j] + (1.0 - lam) * img2[i][j]
            row.append(round(val, 4))
        mixed_img.append(row)
    mixed_lbl = [round(lam * label1[k] + (1.0 - lam) * label2[k], 4) for k in range(len(label1))]
    return {"image": mixed_img, "label": mixed_lbl}
```

Convex combinations of both inputs and target label vectors establish linear transitions across decision boundaries.
