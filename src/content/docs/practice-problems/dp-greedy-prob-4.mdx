```python
def max_profit_stock(prices):
    if not prices:
        return 0
    min_price = prices[0]
    max_prof = 0
    for p in prices[1:]:
        if p < min_price:
            min_price = p
        elif p - min_price > max_prof:
            max_prof = p - min_price
    return max_prof
```

Track the minimum price seen so far as the optimal purchase day, evaluating potential profit if selling at current day.
