```python
def global_avg_pool2d(x: list[list[list[float]]]) -> list[float]:
    C = len(x)
    H = len(x[0])
    W = len(x[0][0])
    area = H * W
    out = []
    for c in range(C):
        c_sum = sum(x[c][i][j] for i in range(H) for j in range(W))
        out.append(round(float(c_sum / area), 4))
    return out
```

Averaging each 2D channel across its entire spatial extent produces a compact representation invariant to spatial translations.
