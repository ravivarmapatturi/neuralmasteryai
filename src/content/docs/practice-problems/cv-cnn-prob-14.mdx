```python
def pointwise_conv2d(x: list[list[list[float]]], weights: list[list[float]], bias: list[float]) -> list[list[list[float]]]:
    C_in = len(x)
    H = len(x[0])
    W = len(x[0][0])
    C_out = len(weights)

    out = []
    for co in range(C_out):
        co_mat = []
        b = bias[co]
        for i in range(H):
            row = []
            for j in range(W):
                val = sum(weights[co][ci] * x[ci][i][j] for ci in range(C_in)) + b
                row.append(round(float(val), 4))
            co_mat.append(row)
        out.append(co_mat)
    return out
```

Pointwise 1x1 convolution applies an affine transformation along the channel axis independently at each spatial pixel.
