```python
import math

def layer_norm(features, gamma, beta, eps=1e-5):
    out = []
    for row in features:
        D = len(row)
        mu = sum(row) / D
        var = sum((x - mu) ** 2 for x in row) / D
        denom = math.sqrt(var + eps)
        normed = [round(float(((x - mu) / denom) * g + b), 4) for x, g, b in zip(row, gamma, beta)]
        out.append(normed)
    return out
```

Computes mean and variance across feature axis, scales by inverse standard deviation, and applies affine parameters.
