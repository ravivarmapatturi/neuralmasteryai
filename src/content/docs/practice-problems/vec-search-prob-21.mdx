## Overview

Implement the scatter-gather merge step every distributed vector search does: each shard returns its own top-k, and the query router must merge them into one global top-k.

## Task

Implement `merge_shard_topk(shard_results, k)`. Each element of `shard_results` is a list of `(id, score)` tuples, already sorted descending by score within its shard (higher score = more relevant). Merge all shards' results and return the global top-`k` `(id, score)` tuples sorted descending by score; ties broken by id ascending.
