```python
def list_depth(nested):
    if not isinstance(nested, list):
        return 0
    if not nested:
        return 1
    return 1 + max(list_depth(item) for item in nested)
```

Recursively inspecting each element and taking 1 + maximum sub-depth computes tree depth in O(N) where N is the total count of elements and sub-lists.
