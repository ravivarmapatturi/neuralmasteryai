```python
import math

def stream_sliding_percentile(nums, window_size, percentile):
    if window_size <= 0 or len(nums) < window_size:
        return []
    res = []
    rank_idx = max(0, math.ceil(percentile * window_size) - 1)
    for i in range(len(nums) - window_size + 1):
        window = sorted(nums[i:i + window_size])
        res.append(round(float(window[rank_idx]), 4))
    return res
```

Nearest-rank indexing retrieves robust distribution quantiles across streaming intervals.
