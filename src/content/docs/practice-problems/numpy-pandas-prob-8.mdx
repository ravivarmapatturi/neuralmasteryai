Reshape relational records into a two-dimensional cross-tabulated pivot summary using Pandas. Prerequisite: `numpy-pandas-prob-7`.

<Solution>

```python
import pandas as pd

def pivot_sales_summary(records, index_key, columns_key, values_key):
    if not records:
        return {}
    df = pd.DataFrame(records)
    pivot = df.pivot_table(index=index_key, columns=columns_key, values=values_key, aggfunc='sum', fill_value=0.0)
    pivot = pivot.sort_index().reindex(columns=sorted(pivot.columns))
    res = {}
    for idx in pivot.index:
        res[str(idx)] = {str(col): round(float(pivot.loc[idx, col]), 2) for col in pivot.columns}
    return res
```

Pandas pivot_table re-indexes categorical coordinate pairs onto a 2D dense grid, aggregating duplicate observations with vector sum and filling structural zeros.
