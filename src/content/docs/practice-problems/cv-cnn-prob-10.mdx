```python
def receptive_field_1d(kernel_sizes: list[int], strides: list[int]) -> dict:
    rf = 1
    stride = 1
    for k, s in zip(kernel_sizes, strides):
        rf = rf + (k - 1) * stride
        stride = stride * s
    return {"receptive_field": rf, "cumulative_stride": stride}
```

Each successive layer broadens the effective input patch by its kernel extent scaled by the preceding cumulative feature map stride.
