```python
def expanding_percentile_rank(series):
    ranks = []
    for i in range(len(series)):
        sub = series[:i + 1]
        curr = series[i]
        pct = (sum(1 for x in sub if x <= curr) / len(sub)) * 100.0
        ranks.append(round(float(pct), 4))
    return ranks
```

Computes running relative position in empirical cumulative distribution at each step.
