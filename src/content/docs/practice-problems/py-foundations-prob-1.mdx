```python
def count_frequencies(items):
    freq = {}
    for item in items:
        freq[item] = freq.get(item, 0) + 1
    return freq
```

Counting frequencies is the core building block for vocabulary building, TF-IDF, bag-of-words representations, and categorical probability distributions.
