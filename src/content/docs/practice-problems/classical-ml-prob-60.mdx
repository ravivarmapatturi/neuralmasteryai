```python
def mean_reciprocal_rank(recommendation_lists, relevant_items):
    rrs = []
    for recs, rels in zip(recommendation_lists, relevant_items):
        rel_set = set(rels)
        rr = 0.0
        for rank, item in enumerate(recs, start=1):
            if item in rel_set:
                rr = 1.0 / rank
                break
        rrs.append(rr)
    mrr = sum(rrs) / len(rrs) if rrs else 0.0
    return round(float(mrr), 4)
```

MRR emphasizes the position of the first successful match, rewarding models that place a correct recommendation at rank 1.
