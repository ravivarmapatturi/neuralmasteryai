## Overview

Search for a target value in a sorted array that has been circularly rotated, maintaining O(log n) time complexity.

## Task

Implement `search_rotated_array(nums, target)`: determine which half of the array [lo..mid] or [mid..hi] is sorted, then check if target falls within that sorted segment to narrow down the search window.

<Solution>

```python
def search_rotated_array(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1
```

Compare nums[lo] and nums[mid] to determine which half is normally sorted. Check if the target is within the sorted range; if yes, narrow into it, otherwise search the opposite half.

</Solution>
