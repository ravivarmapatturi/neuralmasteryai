```python
def wasserstein_1d(p, q):
    cdf_p = 0.0
    cdf_q = 0.0
    w1 = 0.0
    for i in range(len(p)):
        cdf_p += p[i]
        cdf_q += q[i]
        w1 += abs(cdf_p - cdf_q)
    return round(float(w1), 4)
```

Evaluates cumulative distribution functions and integrates absolute discrepancy along the real line.
