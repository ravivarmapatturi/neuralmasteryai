```python
def streaming_macd(prices, fast_period, slow_period, signal_period):
    if not prices:
        return []
    alpha_fast = 2.0 / (fast_period + 1.0)
    alpha_slow = 2.0 / (slow_period + 1.0)
    alpha_signal = 2.0 / (signal_period + 1.0)

    fast_ema = prices[0]
    slow_ema = prices[0]
    macd = fast_ema - slow_ema
    signal_ema = macd

    out = [{
        "fast_ema": round(fast_ema, 4),
        "slow_ema": round(slow_ema, 4),
        "macd": round(macd, 4),
        "signal": round(signal_ema, 4)
    }]

    for p in prices[1:]:
        fast_ema = alpha_fast * p + (1.0 - alpha_fast) * fast_ema
        slow_ema = alpha_slow * p + (1.0 - alpha_slow) * slow_ema
        macd = fast_ema - slow_ema
        signal_ema = alpha_signal * macd + (1.0 - alpha_signal) * signal_ema
        out.append({
            "fast_ema": round(fast_ema, 4),
            "slow_ema": round(slow_ema, 4),
            "macd": round(macd, 4),
            "signal": round(signal_ema, 4)
        })
    return out
```

MACD reveals momentum shifts by contrasting short-term and long-term exponential moving averages against an exponential signal baseline.
