```python
import math

def rmsprop_step(param: list[float], grad: list[float], square_avg: list[float], lr: float = 0.01, alpha: float = 0.99, eps: float = 1e-8) -> dict:
    new_p = []
    new_sq = []
    for p, g, sq in zip(param, grad, square_avg):
        sq_t = alpha * sq + (1.0 - alpha) * (g ** 2)
        p_t = p - (lr / (math.sqrt(sq_t) + eps)) * g
        new_sq.append(round(sq_t, 6))
        new_p.append(round(p_t, 6))
    return {"param": new_p, "square_avg": new_sq}
```

RMSprop divides the gradient by the square root of an exponential moving average of squared gradients, maintaining steady learning rates on non-convex surfaces.
