Implement vectorized min-max normalization in NumPy to scale numerical feature values into the range [0.0, 1.0]. Prerequisite: `math-num-prob-60`.

<Solution>

```python
import numpy as np

def min_max_scale(data):
    if not data:
        return []
    arr = np.array(data, dtype=float)
    min_val = float(np.min(arr))
    max_val = float(np.max(arr))
    if max_val == min_val:
        return [0.0] * len(data)
    scaled = (arr - min_val) / (max_val - min_val)
    return [round(float(x), 4) for x in scaled]
```

Vectorized min-max scaling subtracts the minimum and divides by the range across the entire NumPy array simultaneously, avoiding Python loop overhead while bounding feature domains to [0, 1].

</Solution>
