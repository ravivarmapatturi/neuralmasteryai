```python
def dbscan_region_query(points, point_idx, eps):
    target = points[point_idx]
    neighbors = []
    eps_sq = eps * eps
    for idx, p in enumerate(points):
        dist_sq = sum((pi - ti) ** 2 for pi, ti in zip(p, target))
        if dist_sq <= eps_sq + 1e-12:
            neighbors.append(idx)
    neighbors.sort()
    return neighbors
```

The epsilon-neighborhood cardinality determines whether a point is a core point, border point, or noise point in DBSCAN.
