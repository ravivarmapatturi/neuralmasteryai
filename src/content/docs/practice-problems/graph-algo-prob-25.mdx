```python
from collections import deque

def shortest_path_visiting_all_nodes(graph):
    n = len(graph)
    target_mask = (1 << n) - 1
    q = deque([(i, 1 << i, 0) for i in range(n)])
    visited = {(i, 1 << i) for i in range(n)}
    while q:
        node, mask, steps = q.popleft()
        if mask == target_mask:
            return steps
        for nbr in graph[node]:
            next_mask = mask | (1 << nbr)
            if (nbr, next_mask) not in visited:
                visited.add((nbr, next_mask))
                q.append((nbr, next_mask, steps + 1))
    return 0
```

Execute multi-source BFS over the compound state space (current_node, visited_bitmask). The first time any path reaches full mask coverage gives the minimal step count.
