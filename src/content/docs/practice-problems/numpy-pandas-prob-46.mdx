```python
def pairwise_jaccard_similarity(matrix_a, matrix_b):
    res = []
    for u in matrix_a:
        row = []
        for v in matrix_b:
            intersection = sum(1 for a, b in zip(u, v) if a == 1 and b == 1)
            union = sum(1 for a, b in zip(u, v) if a == 1 or b == 1)
            sim = (intersection / union) if union > 0 else 1.0
            row.append(round(float(sim), 4))
        res.append(row)
    return res
```

Jaccard similarity measures the ratio of shared binary attributes over total active attributes, insensitive to shared absent features.
