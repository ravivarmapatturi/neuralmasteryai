```python
def path_sum_ii(root, target_sum):
    result = []

    def dfs(node, current, path):
        if not node:
            return
        current += node['val']
        path.append(node['val'])
        if not node['left'] and not node['right'] and current == target_sum:
            result.append(list(path))
        dfs(node['left'], current, path)
        dfs(node['right'], current, path)
        path.pop()  # backtrack

    dfs(root, 0, [])
    return result
```

DFS with a running sum and path list. At every leaf check if the sum equals target. `path.pop()` on the way back is the backtracking step. O(n^2) worst case (copying paths).
