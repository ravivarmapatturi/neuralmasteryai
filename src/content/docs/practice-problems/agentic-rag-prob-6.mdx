## Overview

Implement real query decomposition, splitting a compound multi-part question into independently-retrievable subquestions -- a real, standard technique for questions naive single-shot retrieval handles poorly.

## Task

Implement `decompose_question(question)`. Split on the literal string `' and '` (case-sensitive, surrounded by spaces). Strip whitespace from each part and drop any empty results. If there's no `' and '` in the question, return `[question]` unchanged (a single-part question).
