```python
def lasso_coordinate_descent_step(rho_j, z_j, l1_lambda):
    if rho_j < -l1_lambda:
        s = rho_j + l1_lambda
    elif rho_j > l1_lambda:
        s = rho_j - l1_lambda
    else:
        s = 0.0
    w_j = s / z_j if abs(z_j) > 1e-9 else 0.0
    return round(float(w_j), 4)
```

Evaluates proximal operator of L1 norm to enforce exact sparsity.
