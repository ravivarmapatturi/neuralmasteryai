```python
def ffill_with_limit(series, limit):
    out = []
    last_val = None
    consec = 0
    for x in series:
        if x is not None:
            last_val = x
            consec = 0
            out.append(x)
        else:
            if last_val is not None and consec < limit:
                consec += 1
                out.append(last_val)
            else:
                out.append(None)
    return out
```

Constrained forward-filling prevents stale observations from propagating through prolonged sensor outages.
