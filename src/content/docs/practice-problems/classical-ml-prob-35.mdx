```python
def svm_hinge_loss(y_true, x, w, b):
    act = sum(a * wt for a, wt in zip(x, w)) + b
    margin = y_true * act
    loss = max(0.0, 1.0 - margin)
    return round(float(loss), 4)
```

Hinge loss incurs zero penalty when samples lie on or beyond the correct margin boundary, enforcing sparsity in support vectors.
