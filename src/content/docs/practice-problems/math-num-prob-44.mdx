```python
import math

def monte_carlo_integrate(samples_f, a, b):
    N = len(samples_f)
    if N == 0:
        return {'estimate': 0.0, 'standard_error': 0.0}
    mean_f = sum(samples_f) / N
    interval = b - a
    estimate = interval * mean_f
    if N > 1:
        sample_var = sum((x - mean_f) ** 2 for x in samples_f) / (N - 1)
        se = interval * math.sqrt(sample_var / N)
    else:
        se = 0.0
    return {'estimate': round(float(estimate), 4), 'standard_error': round(float(se), 4)}
```

Evaluates the sample mean scaled by domain volume and estimates error via central limit theorem.
