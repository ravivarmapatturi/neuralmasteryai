```python
def simulate_token_bucket(events, capacity, refill_rate):
    tokens = float(capacity)
    last_time = 0.0
    res = []
    for ts, cost in events:
        elapsed = ts - last_time
        tokens = min(float(capacity), tokens + elapsed * refill_rate)
        last_time = ts
        if tokens >= cost:
            tokens -= cost
            res.append(True)
        else:
            res.append(False)
    return res
```

Token buckets accumulate tokens continuously up to capacity; incoming requests consume tokens if available, otherwise they are dropped without deducting tokens.
