## Overview

Implement `flatten_nested_list(nested)`: recursively unpack an arbitrarily nested hierarchy of lists into a flat 1D sequence, maintaining the relative order of all leaf elements.

## Task

Implement the function `flatten_nested_list(nested)`: return a flat list containing all non-list items in `nested` in their original order. Empty sublists should be cleanly bypassed. If `nested` contains no leaf elements, return `[]`.

<Solution>

```python
def flatten_nested_list(nested):
    res = []
    def _flatten(item):
        if isinstance(item, list):
            for sub in item:
                _flatten(sub)
        else:
            res.append(item)
    _flatten(nested)
    return res
```

Recursive tree traversal over nested data structures is a key prerequisite for AST processing, document parsing, and recursive JSON decoding.

</Solution>
