## Overview

Implement `subarray_sum(nums, k)` via the prefix-sum-plus-hash-map trick -- the technique that makes this solvable in O(n) even with negative numbers present, where a sliding window would fail.

## Task

Implement the function `subarray_sum(nums, k)`: return the number of contiguous subarrays of `nums` whose elements sum to exactly `k`. `nums` may contain negative numbers.
