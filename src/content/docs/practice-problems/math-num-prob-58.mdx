```python
def gauss_seidel_iteration(A, b, x0, num_iters=5):
    n = len(b)
    x = list(x0)
    for _ in range(num_iters):
        for i in range(n):
            sum_known = sum(A[i][j] * x[j] for j in range(n) if j != i)
            x[i] = (b[i] - sum_known) / A[i][i]
    return [round(float(v), 4) for v in x]
```

Updates state vector in place so subsequent coordinate updates within the same iteration benefit from newer estimates.
