**Difficulty: Hard** · Concept: [Foundation Model Internals — Attention Variants: MHA, GQA, MQA, MLA](/docs/llms-genai/foundation-model-internals#attention-variants-mha-gqa-mqa-mla)

Standard multi-head attention (MHA) gives every query head its own key/value head. GQA sits between MHA and multi-query attention (MQA, where *every* query head shares one single key/value head): query heads are split into groups, and all the heads within a group share one key/value head. Fewer, shared K/V heads means a much smaller KV cache to store during generation — the real, practical reason GQA is standard in LLaMA 2/3, Mistral, and most current serving-efficient LLMs, trading a small amount of quality for a large memory/bandwidth win.

**Your task**: implement `grouped_query_attention(Q, K, V, num_kv_groups)` where `Q` has shape `(num_heads, seq_len, d)` and `K, V` have shape `(num_kv_groups, seq_len, d)` — query head `h` should use key/value group `h // (num_heads // num_kv_groups)`.
