```python
def top_k_elements(arr, k):
    indexed = [(val, idx) for idx, val in enumerate(arr)]
    indexed.sort(key=lambda x: (-x[0], x[1]))
    top = indexed[:k]
    return {'values': [round(float(x[0]), 4) for x in top], 'indices': [x[1] for x in top]}
```

Pair values with indices, sort by descending value and ascending index, and return top k.
