```python
def zero_padding2d(x: list[list[float]], pad_h: int, pad_w: int) -> list[list[float]]:
    H = len(x)
    W = len(x[0])
    new_H = H + 2 * pad_h
    new_W = W + 2 * pad_w
    padded = [[0.0 for _ in range(new_W)] for _ in range(new_H)]
    for i in range(H):
        for j in range(W):
            padded[i + pad_h][j + pad_w] = float(x[i][j])
    return padded
```

Constructing an expanded zero matrix and placing the original values at offset [pad_h, pad_w] implements symmetric zero-padding.
