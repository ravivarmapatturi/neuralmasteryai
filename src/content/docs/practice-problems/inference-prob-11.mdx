## Overview

Maintain autoregressive key and value states during incremental decoding with optional sliding window eviction. Autoregressive language models generate sequences token by token, evaluating next-token probability distributions at each decoding step.

## Task

Implement `update_kv_cache(cached_keys, cached_values, new_key, new_value, window_size=None)`. Verify that `len(new_key) == len(new_value)` and that their dimensions match existing cached entries (if any). Append `new_key` to `cached_keys` and `new_value` to `cached_values`. If `window_size` is specified, retain only the most recent `window_size` vectors, evicting older entries from the front. If `window_size <= 0`, raise `ValueError`. Return a dict containing `keys`, `values`, `seq_len` (int), and `evicted_count` (int).
