## Overview

Implement Kingma and Ba's adaptive moment estimation (Adam) optimizer step with bias correction.

## Task

Implement `adam_optimizer_step(...)`: at timestep `t >= 1`, compute for each parameter: `m_t = beta1 * m + (1 - beta1) * g`, `v_t = beta2 * v + (1 - beta2) * g^2`. Correct bias: `m_hat = m_t / (1 - beta1^t)`, `v_hat = v_t / (1 - beta2^t)`. Update parameter: `param = param - lr * m_hat / (sqrt(v_hat) + eps)`. Return `{'param': ..., 'm': ..., 'v': ...}` rounded to 6 decimal places.

<Solution>

```python
def adam_optimizer_step(param: list[float], grad: list[float], m: list[float], v: list[float], t: int, lr: float = 0.001, beta1: float = 0.9, beta2: float = 0.999, eps: float = 1e-8) -> dict:
    new_p = []
    new_m = []
    new_v = []
    b1_corr = 1.0 - (beta1 ** t)
    b2_corr = 1.0 - (beta2 ** t)
    for p, g, m_prev, v_prev in zip(param, grad, m, v):
        m_t = beta1 * m_prev + (1.0 - beta1) * g
        v_t = beta2 * v_prev + (1.0 - beta2) * (g ** 2)
        m_hat = m_t / b1_corr
        v_hat = v_t / b2_corr
        p_t = p - lr * m_hat / (math.sqrt(v_hat) + eps)
        new_p.append(round(p_t, 6))
        new_m.append(round(m_t, 6))
        new_v.append(round(v_t, 6))
    return {"param": new_p, "m": new_m, "v": new_v}
```

Adam combines the advantages of AdaGrad (frequent gradient dampening) and RMSprop (moving average scaling) alongside momentum.
