```python
import math

def pairwise_euclidean_distance(x, y):
    res = []
    for u in x:
        row = []
        for v in y:
            dist_sq = sum((a - b) ** 2 for a, b in zip(u, v))
            dist = math.sqrt(max(0.0, dist_sq))
            row.append(round(float(dist), 4))
        res.append(row)
    return res
```

Vectorized pairwise Euclidean distance uses the quadratic expansion ||x - y||^2 = ||x||^2 + ||y||^2 - 2(x . y) for high-performance vectorized evaluation.
