## Overview

Implement `two_sum(nums, target)`, the canonical hash-map problem: an O(n) single-pass solution replacing the naive O(n^2) check of every pair, by trading memory for time.

## Task

Implement the function `two_sum(nums, target)`: return the indices `[i, j]` (with `i < j`) of the two numbers in `nums` that add up to `target`. Exactly one valid pair exists per input, and you may not use the same element twice. Raise `ValueError` if no pair sums to target.
