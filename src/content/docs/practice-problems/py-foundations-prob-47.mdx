```python
def rabin_karp_find(text, pattern):
    if not pattern or not text or len(pattern) > len(text):
        return []
    n, m = len(text), len(pattern)
    base, mod = 256, 1000000007
    p_hash, t_hash = 0, 0
    h = pow(base, m - 1, mod)
    for i in range(m):
        p_hash = (base * p_hash + ord(pattern[i])) % mod
        t_hash = (base * t_hash + ord(text[i])) % mod
    matches = []
    for i in range(n - m + 1):
        if p_hash == t_hash and text[i:i + m] == pattern:
            matches.append(i)
        if i < n - m:
            t_hash = (base * (t_hash - ord(text[i]) * h) + ord(text[i + m])) % mod
    return matches
```

Rabin-Karp maintains an O(1) rolling hash window across the stream, comparing characters only upon hash equality.
