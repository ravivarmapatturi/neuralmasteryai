```python
def range_sum_bst(root, low, high):
    if not root:
        return 0
    total = root['val'] if low <= root['val'] <= high else 0
    if root['val'] > low:
        total += range_sum_bst(root['left'], low, high)
    if root['val'] < high:
        total += range_sum_bst(root['right'], low, high)
    return total
```

BST ordering lets you skip the left subtree when `root.val <= low` and the right subtree when `root.val >= high`. O(n) worst case, much better in practice.
