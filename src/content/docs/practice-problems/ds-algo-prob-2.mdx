```python
from collections import deque

def level_order(root):
    if not root:
        return []
    result = []
    q = deque([root])
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node['val'])
            if node['left']:
                q.append(node['left'])
            if node['right']:
                q.append(node['right'])
        result.append(level)
    return result
```

Snapshot `len(q)` before the inner loop -- that count equals one level's nodes. Enqueue children for the next level. O(n) time, O(n) space.
