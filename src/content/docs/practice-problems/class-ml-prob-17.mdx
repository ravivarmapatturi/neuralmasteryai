## Overview

Implement k-nearest neighbors classification with majority voting from scratch.

## Task

Implement `knn_classify(X_train, y_train, X_test, k)`: for each test sample, compute Euclidean distance to all training samples, find the k nearest neighbors, and return the majority label.

<Solution>

```python
import math

def knn_classify(X_train, y_train, X_test, k):
    res = []
    for test_pt in X_test:
        dists = []
        for i, train_pt in enumerate(X_train):
            d = math.sqrt(sum((a - b) ** 2 for a, b in zip(test_pt, train_pt)))
            dists.append((d, y_train[i]))
        dists.sort(key=lambda x: x[0])
        neighbors = dists[:k]
        votes = {}
        for _, lbl in neighbors:
            votes[lbl] = votes.get(lbl, 0) + 1
        best_lbl = sorted(votes.keys(), key=lambda l: (-votes[l], l))[0]
        res.append(best_lbl)
    return res
```

Find the k nearest training samples under Euclidean distance for each query point and predict the most frequent neighbor label.
