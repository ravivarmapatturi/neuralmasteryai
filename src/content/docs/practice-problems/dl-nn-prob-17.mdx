## Overview

Mitigate exploding gradients in deep neural networks and recurrent models by scaling down gradients when their L2 norm exceeds a threshold.

## Task

Implement `grad_clip_by_norm(grads, max_norm)`: compute the global L2 norm `norm = sqrt(sum(g_i^2))`. If `norm > max_norm`, scale each gradient element by `max_norm / norm`; otherwise leave gradients unchanged. Return `{'clipped_grads': [...], 'global_norm': norm}` with all numbers rounded to 6 decimal places.

<Solution>

```python
def grad_clip_by_norm(grads: list[float], max_norm: float) -> dict:
    global_norm = math.sqrt(sum(g ** 2 for g in grads))
    if global_norm <= max_norm or global_norm == 0.0:
        scale = 1.0
    else:
        scale = max_norm / global_norm
    return {"clipped_grads": [round(g * scale, 6) for g in grads], "global_norm": round(global_norm, 6)}
```

By scaling all elements by min(1, max_norm / norm), the relative direction of the gradient vector is maintained without exceeding max_norm.

</Solution>
