```python
def moving_average_1d(signal, window_size):
    n = len(signal)
    if window_size > n or window_size <= 0:
        return []
    curr_sum = sum(signal[:window_size])
    res = [round(float(curr_sum / window_size), 4)]
    for i in range(window_size, n):
        curr_sum += signal[i] - signal[i - window_size]
        res.append(round(float(curr_sum / window_size), 4))
    return res
```

Updates sliding window sum in O(1) time per element and divides by window width.
