Construct a multi-class confusion matrix from ground-truth and predicted labels using vectorized NumPy operations. Prerequisite: `numpy-pandas-prob-12`.

<Solution>

```python
import numpy as np

def vectorized_confusion_matrix(y_true, y_pred, num_classes):
    if num_classes <= 0:
        return []
    if not y_true or not y_pred or len(y_true) != len(y_pred):
        return np.zeros((num_classes, num_classes), dtype=int).tolist()
    yt = np.array(y_true, dtype=int)
    yp = np.array(y_pred, dtype=int)
    flat_indices = yt * num_classes + yp
    counts = np.bincount(flat_indices, minlength=num_classes * num_classes)
    matrix = counts.reshape((num_classes, num_classes))
    return matrix.tolist()
```

Linear indexing combines row and column coordinates into flat 1D addresses, enabling np.bincount to tally all bin frequencies in optimized C in a single linear pass.

</Solution>
