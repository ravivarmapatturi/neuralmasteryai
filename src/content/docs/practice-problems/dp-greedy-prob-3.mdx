```python
def can_place_flowers(flowerbed, n):
    count = 0
    beds = list(flowerbed)
    length = len(beds)
    for i in range(length):
        if beds[i] == 0:
            left = (i == 0 or beds[i - 1] == 0)
            right = (i == length - 1 or beds[i + 1] == 0)
            if left and right:
                beds[i] = 1
                count += 1
                if count >= n:
                    return True
    return count >= n
```

Greedily plant in any valid plot (0 with 0 neighbors). Early placement maximizes available future slots without reducing capacity.
