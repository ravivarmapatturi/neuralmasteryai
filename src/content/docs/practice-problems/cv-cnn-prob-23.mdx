```python
def conv2d_backward_weights(input_map: list[list[float]], grad_output: list[list[float]], kernel_size: int = 3, stride: int = 1) -> list[list[float]]:
    H_out = len(grad_output)
    W_out = len(grad_output[0])
    grad_w = []
    for ki in range(kernel_size):
        row = []
        for kj in range(kernel_size):
            val = sum(grad_output[i][j] * input_map[i * stride + ki][j * stride + kj] for i in range(H_out) for j in range(W_out))
            row.append(round(val, 4))
        grad_w.append(row)
    return grad_w
```

Cross-correlating the input feature activation patches with upstream gradients yields the exact analytical weight updates.
