```python
def polynomial_features_1d(x, degree):
    out = []
    for val in x:
        row = [round(float(val ** d), 4) for d in range(degree + 1)]
        out.append(row)
    return out
```

Polynomial feature transformation allows linear models to capture non-linear relationships by computing explicit power interaction terms.
