# Numerically Stable Softmax From Scratch

**Difficulty: Medium** · Concept: [Activation Functions — Auxiliary Functions](/docs/deep-learning/activation-functions#auxiliary-functions)

$$\text{softmax}(\mathbf{z})_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

Unlike [sigmoid](/practice/sigmoid-activation), softmax operates on a whole vector at once, turning raw scores ("logits") into a probability distribution that sums to 1 — the standard output layer for multi-class classification, and exactly what turns an LLM's raw next-token scores into a probability distribution over the vocabulary.

**Your task**: implement `softmax(z)` for a list of real numbers. The naive formula above overflows for large inputs — `math.exp(1000)` raises `OverflowError` in plain Python — so your implementation needs to be numerically stable: it must return correct results even when every value in `z` is large.

<Solution>

```python
import math

def softmax(z):
    m = max(z)
    exps = [math.exp(zi - m) for zi in z]
    total = sum(exps)
    return [e / total for e in exps]
```

**The trick**: subtract the maximum value in `z` from every element before exponentiating. This doesn't change the mathematical result — $\frac{e^{z_i - m}}{\sum_j e^{z_j - m}} = \frac{e^{z_i}e^{-m}}{\sum_j e^{z_j}e^{-m}} = \frac{e^{z_i}}{\sum_j e^{z_j}}$, since the $e^{-m}$ factor cancels top and bottom — but it changes the *numerics* completely: after subtracting the max, the largest exponent being computed is always `exp(0) = 1`, and every other exponent is `exp(negative number)`, which safely underflows toward 0 instead of overflowing. This is exactly why `softmax([1000, 1000, 1000])` still works above (every element becomes `exp(0)`, giving the correct uniform `[1/3, 1/3, 1/3]`) instead of crashing.

This is not a toy edge case — real transformer attention logits and LLM output logits routinely reach magnitudes in the hundreds or thousands before softmax, so every production softmax implementation (PyTorch's, NumPy's, JAX's) does exactly this max-subtraction internally. [Attention & Transformers](/docs/deep-learning/attention-transformers) uses this same softmax to turn raw attention scores into attention weights.
