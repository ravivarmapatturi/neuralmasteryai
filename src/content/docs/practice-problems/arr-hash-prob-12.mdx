## Overview

Implement `product_except_self(nums)` via two passes (prefix products, then suffix products) -- the classic no-division answer that also correctly handles zeros in the input.

## Task

Implement the function `product_except_self(nums)`: return a list where `result[i]` is the product of every element in `nums` except `nums[i]`. Must not use division, and must run in O(n) time.
