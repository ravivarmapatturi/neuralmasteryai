```python
from collections import deque

def max_sliding_window(nums, k):
    result = []
    dq = deque()  # stores indices; front = index of current window's max
    for i, n in enumerate(nums):
        # Remove elements outside the window
        if dq and dq[0] == i - k:
            dq.popleft()
        # Maintain decreasing order: remove smaller elements from back
        while dq and nums[dq[-1]] <= n:
            dq.pop()
        dq.append(i)
        # Window is full
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

Monotonic decreasing deque of indices. For each new element, pop the back while it is smaller (they can never be the maximum). Pop the front if it's out of the window. O(n) time -- each index pushed and popped at most once.
