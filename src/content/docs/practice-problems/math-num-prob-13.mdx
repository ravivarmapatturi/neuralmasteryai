```python
def quadratic_hessian(A):
    n = len(A)
    H = []
    for i in range(n):
        row = []
        for j in range(n):
            val = 0.5 * (A[i][j] + A[j][i])
            row.append(round(float(val), 4))
        H.append(row)
    return H
```

Averages off-diagonal transposes to extract the symmetric second derivative tensor.
