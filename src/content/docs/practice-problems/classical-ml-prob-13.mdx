```python
def r2_score(y_true, y_pred):
    if not y_true:
        return 1.0
    n = len(y_true)
    mean_y = sum(y_true) / n
    ss_tot = sum((yt - mean_y) ** 2 for yt in y_true)
    ss_res = sum((yt - yp) ** 2 for yt, yp in zip(y_true, y_pred))
    if abs(ss_tot) < 1e-12:
        return 1.0 if abs(ss_res) < 1e-12 else 0.0
    return round(1.0 - ss_res / ss_tot, 6)
```

R^2 = 1.0 indicates perfect prediction, R^2 = 0.0 matches predicting the mean, and negative values indicate performance worse than predicting the mean.
