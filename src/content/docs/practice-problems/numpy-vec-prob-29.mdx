```python
def apply_affine_2d(points, transform_mat, translation):
    out = []
    for px, py in points:
        x_new = transform_mat[0][0] * px + transform_mat[0][1] * py + translation[0]
        y_new = transform_mat[1][0] * px + transform_mat[1][1] * py + translation[1]
        out.append([round(float(x_new), 4), round(float(y_new), 4)])
    return out
```

Multiplies each point coordinate with transformation matrix and adds translation offsets.
