```python
def lowest_common_ancestor_bst(root, p, q):
    curr = root
    while curr:
        if p < curr['val'] and q < curr['val']:
            curr = curr['left']
        elif p > curr['val'] and q > curr['val']:
            curr = curr['right']
        else:
            return curr['val']
    return -1
```

Traverse down the tree: as long as both p and q are on the same side of the current node, descend into that side. The first node where they diverge (or one equals current) is the LCA.
