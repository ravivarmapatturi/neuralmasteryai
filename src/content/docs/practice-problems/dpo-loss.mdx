**Difficulty: Medium** · Topic: LLMs & GenAI · Concept: [RLHF & Direct Preference Optimization](/docs/ai-safety/alignment-and-rlhf)

$$\mathcal{L}_{\text{DPO}}(\theta; \pi_{\text{ref}}) = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)} \right) \right]$$

DPO directly aligns LLM policy parameters with human preferences without training an explicit reward model or running complex PPO reinforcement learning loops. In this challenge, implement the DPO loss computation in NumPy.

<Solution>

```python
import numpy as np

def dpo_loss(policy_chosen_logps, policy_rejected_logps, ref_chosen_logps, ref_rejected_logps, beta=0.1):
    """
    Computes average DPO loss over a batch of preferred (chosen) and dispreferred (rejected) log probabilities.
    Returns scalar loss float.
    """
    pi_logratios = policy_chosen_logps - policy_rejected_logps
    ref_logratios = ref_chosen_logps - ref_rejected_logps

    logits = beta * (pi_logratios - ref_logratios)

    # Numerically stable -log(sigmoid(logits)) = softplus(-logits)
    losses = np.log1p(np.exp(-logits))
    return float(np.mean(losses))
```

DPO calculates log probability ratios between policy $\pi_\theta$ and reference model $\pi_{\text{ref}}$ for chosen ($y_w$) versus rejected ($y_l$) responses. Multiplying by hyperparameter $\beta$ scales implicit reward differences, and $-\log \sigma(\text{logits})$ penalizes cases where the policy favors rejected responses over chosen ones.
