# AdamW Optimizer Step From Scratch

**Difficulty: Medium** · Topic: Deep Learning · Concept: [Optimizers & Training](/docs/deep-learning/optimizers)

$$\hat{m}_t = \frac{m_t}{1 - \beta_1^t}, \quad \hat{v}_t = \frac{v_t}{1 - \beta_2^t}, \quad \theta_t = \theta_{t-1} - \gamma \left( \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon} + \lambda \theta_{t-1} \right)$$

AdamW decouples weight decay from gradient updates, preventing L2 regularization from distorting Adam's adaptive learning rates. In this challenge, implement a single AdamW parameter update step in pure NumPy, using the standard defaults $\beta_1=0.9$, $\beta_2=0.999$, $\epsilon=10^{-8}$ unless the caller overrides them — `param`, `grad`, `m`, and `v` are lists (elementwise over every parameter), and `next_param`/`next_m`/`next_v` must each come back as a list the same length as `param`, not flattened into one combined list.

```python
import numpy as np

def adamw_step(param, grad, m, v, t, lr=0.001, beta1=0.9, beta2=0.999, eps=1e-8, weight_decay=0.01):
    """
    Returns (next_param, next_m, next_v) after one AdamW step.
    """
    param = np.array(param, dtype=float)
    grad = np.array(grad, dtype=float)
    m = np.array(m, dtype=float)
    v = np.array(v, dtype=float)

    # 1. Update biased 1st and 2nd moment estimates
    m_next = beta1 * m + (1 - beta1) * grad
    v_next = beta2 * v + (1 - beta2) * (grad ** 2)

    # 2. Compute bias-corrected estimates
    m_hat = m_next / (1 - (beta1 ** t))
    v_hat = v_next / (1 - (beta2 ** t))

    # 3. Decoupled weight decay update
    param_next = param - lr * (m_hat / (np.sqrt(v_hat) + eps) + weight_decay * param)

    return param_next, m_next, v_next
```

AdamW maintains exponential moving averages of gradients ($m$) and squared gradients ($v$). Bias correction balances early steps when $m$ and $v$ are initialized at zero. Decoupled weight decay subtracts $\gamma \lambda \theta_{t-1}$ directly from parameters rather than adding it to gradients.
