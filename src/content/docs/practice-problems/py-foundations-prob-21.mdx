```python
def frequency_sort(s):
    counts = {}
    for c in s:
        counts[c] = counts.get(c, 0) + 1
    sorted_chars = sorted(counts.keys(), key=lambda c: (-counts[c], c))
    return "".join(c * counts[c] for c in sorted_chars)
```

Python sorted with tuple key `(-counts[c], c)` naturally sorts primarily by highest frequency and secondarily by alphabetical order.
