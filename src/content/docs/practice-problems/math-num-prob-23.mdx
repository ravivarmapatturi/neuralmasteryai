```python
import math

def adagrad_step(w, grad, accum, lr=0.01, eps=1e-8):
    accum_next = [ac + g ** 2 for ac, g in zip(accum, grad)]
    w_next = [wi - (lr / (math.sqrt(ac_n) + eps)) * g for wi, ac_n, g in zip(w, accum_next, grad)]
    return {'w': [round(float(x), 4) for x in w_next], 'accum': [round(float(x), 4) for x in accum_next]}
```

Maintains sum of past squared gradients to adjust step sizes inversely proportional to gradient magnitude.
