```python
def missingness_report(records, column_names):
    n = len(records)
    out = {}
    for col in column_names:
        missing = 0
        for r in records:
            if col not in r or r[col] is None or r[col] == "":
                missing += 1
        ratio = round(missing / n, 4) if n > 0 else 0.0
        out[col] = {"missing_count": missing, "missing_ratio": ratio}
    return out
```

Iterate through all columns and records, flagging absent keys, None values, and empty strings to compute exact column-level missingness metrics.
