## Overview

Implement `max_sliding_window(nums, k)` to track the maximum element in an evolving window of size `k` in strictly linear time.

## Task

Implement the function `max_sliding_window(nums, k)`: return an array containing the maximum values for each window of length `k` as it slides across `nums`.
