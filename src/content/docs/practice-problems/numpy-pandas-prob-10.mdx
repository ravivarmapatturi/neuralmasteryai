Detect distribution outliers via Interquartile Range (IQR) and clip extreme values using vectorized NumPy operations. Prerequisite: `numpy-pandas-prob-9`.

<Solution>

```python
import numpy as np

def clip_outliers_iqr(data, k=1.5):
    if not data:
        return []
    arr = np.array(data, dtype=float)
    q1 = float(np.percentile(arr, 25))
    q3 = float(np.percentile(arr, 75))
    iqr = q3 - q1
    lower = q1 - k * iqr
    upper = q3 + k * iqr
    clipped = np.clip(arr, lower, upper)
    return [round(float(x), 4) for x in clipped]
```

Winsorizing extreme observations with IQR-derived percentile boundaries stabilizes downstream loss functions and tree split metrics against leverage points.
