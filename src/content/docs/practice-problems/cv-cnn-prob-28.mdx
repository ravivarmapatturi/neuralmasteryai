```python
def fpn_top_down_fusion(higher_level: list[list[float]], lower_level_lateral: list[list[float]]) -> list[list[float]]:
    H = len(higher_level)
    W = len(higher_level[0])
    fused = []
    for i in range(2 * H):
        row = []
        for j in range(2 * W):
            src_r = i // 2
            src_c = j // 2
            val = higher_level[src_r][src_c] + lower_level_lateral[i][j]
            row.append(round(val, 4))
        fused.append(row)
    return fused
```

Nearest-neighbor 2x upsampling doubles spatial dimensions to align with lateral features before element-wise summation.
