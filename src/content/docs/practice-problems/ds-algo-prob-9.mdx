```python
def rob(nums):
    if not nums:
        return 0
    prev2, prev1 = 0, 0
    for n in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + n)
    return prev1
```

Rolling two variables: `prev2` is dp[i-2], `prev1` is dp[i-1]. Each step: `prev2, prev1 = prev1, max(prev1, prev2+n)`. O(n) time, O(1) space.
