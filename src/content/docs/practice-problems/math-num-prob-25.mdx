```python
import math

def adam_step(w, grad, m, v, t=1, lr=0.001, beta1=0.9, beta2=0.999, eps=1e-8):
    m_next = [beta1 * mi + (1.0 - beta1) * gi for mi, gi in zip(m, grad)]
    v_next = [beta2 * vi + (1.0 - beta2) * (gi ** 2) for vi, gi in zip(v, grad)]
    m_hat = [mi_n / (1.0 - beta1 ** t) for mi_n in m_next]
    v_hat = [vi_n / (1.0 - beta2 ** t) for vi_n in v_next]
    w_next = [wi - (lr / (math.sqrt(vh) + eps)) * mh for wi, vh, mh in zip(w, v_hat, m_hat)]
    return {'w': [round(float(x), 4) for x in w_next], 'm': [round(float(x), 4) for x in m_next], 'v': [round(float(x), 4) for x in v_next]}
```

Updates first and second moment moving averages, corrects zero-initialization bias, and applies preconditioned step.
