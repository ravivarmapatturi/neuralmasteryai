## Overview

Re-weight training samples based on classifier correctness in an AdaBoost boosting round.

## Task

Implement `adaboost_weight_update(sample_weights, y_true, predictions, alpha)`: compute unnormalized weight `w_i * exp(-alpha * y_i * h_i)` where `y_i, h_i in {-1, 1}`. Normalize weights so their sum equals 1.0. Round each float to 4 decimal places.

<Solution>

```python
import math

def adaboost_weight_update(sample_weights, y_true, predictions, alpha):
    unnorm = [w * math.exp(-alpha * yt * pred) for w, yt, pred in zip(sample_weights, y_true, predictions)]
    z = sum(unnorm)
    return [round(float(w / z), 4) for w in unnorm]
```

AdaBoost inflates the probability weight of misclassified samples by exp(alpha) and shrinks correct samples by exp(-alpha), focusing subsequent learners on hard examples.

</Solution>
