```python
import heapq

def find_kth_largest(nums, k):
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)
    return heap[0]
```

Keeping a min-heap of capacity k guarantees the root holds the k-th largest element in O(n log k) runtime.
