```python
def image_normalize(img: list[list[list[float]]], mean: list[float], std: list[float]) -> list[list[list[float]]]:
    C = len(img)
    H = len(img[0])
    W = len(img[0][0])
    out = []
    for c in range(C):
        c_mat = []
        m = mean[c]
        s = std[c]
        for i in range(H):
            row = []
            for j in range(W):
                val = (img[c][i][j] - m) / s
                row.append(round(float(val), 4))
            c_mat.append(row)
        out.append(c_mat)
    return out
```

Standardizing each channel by its channel-specific mean and standard deviation aligns the input distribution with pretrained model weights.
