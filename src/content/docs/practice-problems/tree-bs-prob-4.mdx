## Overview

Implement classic `binary_search(nums, target)` from scratch -- the O(log n) algorithm every tree-height-bounded search, and half of this track's own name, is built on.

## Task

Implement the function `binary_search(nums, target)`: `nums` is sorted ascending with distinct values. Return the index of `target`, or `-1` if absent. Must run in O(log n) time.
