## Overview

Implement an RPN (postfix) calculator with a stack -- a representation that needs no parentheses and no operator-precedence rules at all, because operand order already encodes evaluation order.

## Task

Implement the function `eval_rpn(tokens)`: evaluate a Reverse Polish Notation expression using a stack, returning the integer result (division truncates toward zero).
