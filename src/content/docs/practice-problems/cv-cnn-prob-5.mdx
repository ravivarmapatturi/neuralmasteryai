```python
def rgb_to_grayscale(rgb_image: list[list[list[float]]]) -> list[list[float]]:
    H = len(rgb_image[0])
    W = len(rgb_image[0][0])
    gray = []
    for i in range(H):
        row = []
        for j in range(W):
            r = rgb_image[0][i][j]
            g = rgb_image[1][i][j]
            b = rgb_image[2][i][j]
            y = 0.299 * r + 0.587 * g + 0.114 * b
            row.append(round(float(y), 4))
        gray.append(row)
    return gray
```

Weighted linear combination of the color channels according to ITU-R BT.601 yields standard perceptual luminance.
