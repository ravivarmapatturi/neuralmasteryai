```python
def run_length_encode(text):
    if not text:
        return ""
    res = []
    curr_char = text[0]
    count = 1
    for ch in text[1:]:
        if ch == curr_char:
            count += 1
        else:
            res.append(f"{curr_char}{count}")
            curr_char = ch
            count = 1
    res.append(f"{curr_char}{count}")
    return "".join(res)
```

Iterating through characters with an accumulator list and joining once at the end avoids Python quadratic string reallocation overhead.
