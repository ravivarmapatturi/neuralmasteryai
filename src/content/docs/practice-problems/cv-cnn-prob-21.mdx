```python
import math

def bilinear_interpolate(image: list[list[float]], y: float, x: float) -> float:
    H = len(image)
    W = len(image[0])
    y0 = int(math.floor(y))
    y1 = min(H - 1, y0 + 1)
    x0 = int(math.floor(x))
    x1 = min(W - 1, x0 + 1)
    dy = y - y0
    dx = x - x0
    val = (1.0 - dy) * (1.0 - dx) * image[y0][x0] + (1.0 - dy) * dx * image[y0][x1] + dy * (1.0 - dx) * image[y1][x0] + dy * dx * image[y1][x1]
    return round(val, 4)
```

Bilinear interpolation performs two 1D linear interpolations successively along row and column dimensions.
