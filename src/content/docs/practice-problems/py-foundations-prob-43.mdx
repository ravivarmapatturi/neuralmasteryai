```python
def reservoir_sample_step(current_sample, item, item_index, random_val, k):
    res = list(current_sample)
    if item_index <= k:
        res.append(item)
    else:
        replace_idx = int(random_val * item_index)
        if replace_idx < k:
            res[replace_idx] = item
    return res
```

Algorithm R guarantees every stream element has an exact k/N probability of appearing in the final reservoir.
