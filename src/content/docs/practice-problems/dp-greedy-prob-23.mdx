```python
def max_profit_k_transactions(k, prices):
    if not prices or k == 0:
        return 0
    n = len(prices)
    if k >= n // 2:
        return sum(max(0, prices[i] - prices[i - 1]) for i in range(1, n))
    buy = [-float('inf')] * (k + 1)
    sell = [0] * (k + 1)
    for p in prices:
        for i in range(1, k + 1):
            buy[i] = max(buy[i], sell[i - 1] - p)
            sell[i] = max(sell[i], buy[i] + p)
    return sell[k]
```

Track the maximum balance after i-th buy and i-th sell. Update states for each transaction count on each day, returning sell[k].
