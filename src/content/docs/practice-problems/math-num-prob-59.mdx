```python
def sor_iteration(A, b, x0, omega=1.2, num_iters=5):
    n = len(b)
    x = list(x0)
    for _ in range(num_iters):
        for i in range(n):
            sum_known = sum(A[i][j] * x[j] for j in range(n) if j != i)
            gs_val = (b[i] - sum_known) / A[i][i]
            x[i] = (1.0 - omega) * x[i] + omega * gs_val
    return [round(float(v), 4) for v in x]
```

Extrapolates Gauss-Seidel update by convex combination parameter omega to minimize spectral radius.
