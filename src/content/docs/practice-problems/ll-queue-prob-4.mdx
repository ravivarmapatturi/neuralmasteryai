## Overview

Implement Floyd's Tortoise and Hare cycle detection -- two pointers moving at different speeds are guaranteed to meet inside any cycle, using O(1) extra space.

## Task

Implement the function `has_cycle(values, pos)`: build the described linked list (wiring a cycle back to index `pos` if `pos != -1`), then use the slow/fast pointer technique to detect a cycle.
