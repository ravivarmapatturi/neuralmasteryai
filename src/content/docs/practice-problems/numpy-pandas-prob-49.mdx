```python
def rolling_window_strides(values, window_size, step):
    if not values or window_size <= 0 or step <= 0:
        return []
    out = []
    i = 0
    while i + window_size <= len(values):
        win = [round(float(x), 4) for x in values[i : i + window_size]]
        out.append(win)
        i += step
    return out
```

Strided window views partition continuous 1D signals into overlapping segments for spectral analysis and 1D convolutions.
