```python
def variance_reduction(parent_targets, left_targets, right_targets):
    def variance(arr):
        if len(arr) <= 1:
            return 0.0
        m = sum(arr) / len(arr)
        return sum((x - m) ** 2 for x in arr) / len(arr)

    n = len(parent_targets)
    if n == 0:
        return 0.0
    v_parent = variance(parent_targets)
    v_children = (len(left_targets) / n) * variance(left_targets) + (len(right_targets) / n) * variance(right_targets)
    reduction = max(0.0, v_parent - v_children)
    return round(float(reduction), 4)
```

Variance reduction measures MSE improvement from splitting a node into two constant-prediction child leaves.
