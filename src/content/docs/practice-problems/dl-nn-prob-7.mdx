```python
import math

def he_initialization_std(fan_in: int, mode: str = "relu") -> float:
    if mode == "relu":
        gain = math.sqrt(2.0)
    elif mode == "leaky_relu":
        gain = math.sqrt(2.0 / (1.0 + 0.01 ** 2))
    else:
        gain = 1.0
    std = gain / math.sqrt(fan_in)
    return round(std, 6)
```

Because ReLU zeroes out approximately half the incoming inputs, the variance of outputs halves unless weights are scaled by sqrt(2/fan_in).
