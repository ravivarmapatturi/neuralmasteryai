```python
import math

def cholesky_decomposition(A):
    n = len(A)
    L = [[0.0] * n for _ in range(n)]
    for j in range(n):
        sum_sq = sum(L[j][k] ** 2 for k in range(j))
        diag_val = A[j][j] - sum_sq
        if diag_val <= 0:
            return None
        L[j][j] = math.sqrt(diag_val)
        for i in range(j + 1, n):
            sum_cross = sum(L[i][k] * L[j][k] for k in range(j))
            L[i][j] = (A[i][j] - sum_cross) / L[j][j]
    return [[round(float(x), 4) for x in row] for row in L]
```

Constructs the Cholesky factor column by column via Banachiewicz algorithm.
