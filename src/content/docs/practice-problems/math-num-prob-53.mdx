```python
import math

def fft_radix2(x):
    def fft_recurse(seq):
        n = len(seq)
        if n <= 1:
            return seq
        even = fft_recurse(seq[0::2])
        odd = fft_recurse(seq[1::2])
        out = [0.0] * n
        for k in range(n // 2):
            angle = -2.0 * math.pi * k / n
            w = complex(math.cos(angle), math.sin(angle))
            t = w * odd[k]
            out[k] = even[k] + t
            out[k + n // 2] = even[k] - t
        return out
    complex_seq = [complex(v, 0.0) for v in x]
    res = fft_recurse(complex_seq)
    return [[round(float(c.real), 4), round(float(c.imag), 4)] for c in res]
```

Recursively decomposes problem into sub-problems of half-size using twiddle factor symmetry.
