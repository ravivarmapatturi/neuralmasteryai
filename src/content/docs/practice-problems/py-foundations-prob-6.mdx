```python
def cumulative_sum(nums):
    if not nums:
        return []
    res = []
    curr = 0
    for x in nums:
        curr += x
        res.append(curr)
    return res
```

A prefix sum transforms range sum calculations from O(k) per query to O(1), and converting probability mass functions (PMFs) to cumulative distribution functions (CDFs) enables inverse transform sampling.
