## Overview

Implement cycle detection in a wait-for graph, the real, standard technique for detecting deadlock among agents holding and requesting shared resources.

## Task

Implement `has_deadlock(wait_for)`. `wait_for[a]` lists the agents that agent `a` is waiting on. Return `True` if the directed graph contains ANY cycle (a deadlock), else `False`. Use DFS with recursion-stack tracking.
