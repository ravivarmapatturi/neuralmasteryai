## Overview

Derive and compute the analytical backward gradients for a fully-connected affine layer.

## Task

Implement `dense_backward(dout, x, w)`: given upstream gradient `dout` `(N, D_out)`, input cache `x` `(N, D_in)`, and weight matrix `w` `(D_in, D_out)`, compute `dx = dout @ w.T`, `dw = x.T @ dout`, and `db = sum(dout, axis=0)`. Return a dictionary `{'dx': dx, 'dw': dw, 'db': db}` with all numbers rounded to 4 decimal places.

<Solution>

```python
def dense_backward(dout: list[list[float]], x: list[list[float]], w: list[list[float]]) -> dict:
    N = len(x)
    D_in = len(w)
    D_out = len(w[0])

    dx = []
    for i in range(N):
        row = []
        for j in range(D_in):
            val = sum(dout[i][k] * w[j][k] for k in range(D_out))
            row.append(round(float(val), 4))
        dx.append(row)

    dw = []
    for i in range(D_in):
        row = []
        for j in range(D_out):
            val = sum(x[k][i] * dout[k][j] for k in range(N))
            row.append(round(float(val), 4))
        dw.append(row)

    db = []
    for j in range(D_out):
        val = sum(dout[k][j] for k in range(N))
        db.append(round(float(val), 4))

    return {"dx": dx, "dw": dw, "db": db}
```

Following the chain rule: dx = dout @ w^T, dw = x^T @ dout, and db = sum(dout) across the batch dimension N.
