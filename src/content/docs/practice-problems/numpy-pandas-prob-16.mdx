## Overview

Compute numerically stable softmax probabilities across rows of a 2D matrix of logits.

## Task

Implement `vectorized_softmax(scores)` to compute row-wise softmax probabilities. For each row, subtract the row maximum before exponentiating to prevent numerical overflow, then divide by the row exponential sum. Round each probability to 4 decimal places.

<Solution>

```python
import math

def vectorized_softmax(scores):
    res = []
    for row in scores:
        if not row:
            res.append([])
            continue
        max_val = max(row)
        exps = [math.exp(x - max_val) for x in row]
        sum_exps = sum(exps)
        res.append([round(e / sum_exps, 4) for e in exps])
    return res
```

Subtracting the row maximum ensures exponents do not exceed zero, avoiding floating point overflow while preserving relative probability ratios.
