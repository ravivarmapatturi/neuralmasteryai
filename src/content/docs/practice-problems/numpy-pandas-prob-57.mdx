```python
def simulate_leaky_bucket(packets, capacity, leak_rate):
    level = 0.0
    last_time = 0.0
    out = []
    for ts, size in packets:
        elapsed = ts - last_time
        level = max(0.0, level - elapsed * leak_rate)
        last_time = ts
        if level + size <= capacity:
            level += size
            out.append([ts, size, True])
        else:
            out.append([ts, size, False])
    return out
```

Leaky bucket buffers incoming traffic and discharges at a constant rate, eliminating burst spikes to protect downstream backends.
