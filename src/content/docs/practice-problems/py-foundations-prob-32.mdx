```python
def word_wrap(text, max_width):
    words = text.split()
    if not words:
        return []
    lines = []
    curr_line = [words[0]]
    curr_len = len(words[0])
    for w in words[1:]:
        if curr_len + 1 + len(w) <= max_width:
            curr_line.append(w)
            curr_len += 1 + len(w)
        else:
            lines.append(" ".join(curr_line))
            curr_line = [w]
            curr_len = len(w)
    lines.append(" ".join(curr_line))
    return lines
```

Greedy packing checks whether the next token fits within the column limit before advancing to a new line.
