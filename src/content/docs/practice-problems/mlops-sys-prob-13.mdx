## Overview

Implement linear learning-rate warmup, a real, near-universal training stabilization technique for large model training.

## Task

Implement `warmup_lr(step, warmup_steps, base_lr)`. If `step >= warmup_steps` (or `warmup_steps == 0`), return `base_lr`. Otherwise return `base_lr * step / warmup_steps` (linear ramp from 0).
