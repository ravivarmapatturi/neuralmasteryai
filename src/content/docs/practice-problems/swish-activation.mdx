Implement the Swish activation function f(x) = x * sigmoid(beta * x).

<Solution>

```python
import math

def swish(x, beta=1.0):
    return [val / (1.0 + math.exp(-beta * val)) for val in x]
```

Swish is a smooth, non-monotonic activation function discovered via neural architecture search that outperforms ReLU in deep models.
