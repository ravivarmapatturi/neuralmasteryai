## Overview

Implement `deduplicate_preserve_order(items)`: filter out redundant elements while strictly preserving the initial arrival order of each unique item.

## Task

Implement the function `deduplicate_preserve_order(items)`: return a new list with duplicate elements removed, keeping only the first occurrence of each item in order. If `items` is empty, return `[]`.

<Solution>

```python
def deduplicate_preserve_order(items):
    seen = set()
    res = []
    for item in items:
        if item not in seen:
            seen.add(item)
            res.append(item)
    return res
```

Preserving insertion order during deduplication is critical in RAG pipelines where retrieved passages are ranked by relevance score and must not be shuffled.

</Solution>
