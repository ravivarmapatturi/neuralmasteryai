```python
def slope_one_predict(ratings, dev_matrix, count_matrix, target_item):
    num = 0.0
    denom = 0
    for item_i, r_ui in ratings.items():
        if item_i != target_item:
            dev = dev_matrix.get(target_item, {}).get(item_i, 0.0)
            cnt = count_matrix.get(target_item, {}).get(item_i, 0)
            if cnt > 0:
                num += (r_ui + dev) * cnt
                denom += cnt
    pred = num / denom if denom > 0 else 0.0
    return round(float(pred), 4)
```

Slope One tracks pairwise average rating differences between items, providing an intuitive, parameter-free collaborative filtering baseline.
