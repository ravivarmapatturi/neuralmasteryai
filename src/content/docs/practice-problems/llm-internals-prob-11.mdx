## Overview

Calculate the exact VRAM footprint in bytes required by an LLM KV-cache during multi-turn autoregressive serving.

## Task

Implement `calculate_kv_cache_bytes(num_layers, num_kv_heads, head_dim, seq_len, batch_size, bytes_per_param=2)`. Return the total byte count accounting for both Key and Value tensors across all layers, heads, positions, and batch slots.
