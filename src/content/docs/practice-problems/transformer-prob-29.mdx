## Overview

Calculate evaluation perplexity from a sequence of per-token natural log-probabilities. Perplexity is the standard evaluation metric for language models, representing the exponentiated negative mean log-likelihood of test sequences.

## Task

Implement `compute_perplexity(log_probs)`: given a non-empty list of token natural log-probabilities `log_probs`, compute `exp(-mean(log_probs)) = exp(-sum(log_probs) / len(log_probs))`. Return the perplexity rounded to 4 decimal places. If `log_probs` is empty, raise `ValueError`.
