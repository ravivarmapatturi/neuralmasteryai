```python
def residual_block_forward(x: list[list[float]], w1: list[list[float]], b1: list[float], w2: list[list[float]], b2: list[float]) -> list[list[float]]:
    N = len(x)
    D = len(x[0])

    h1 = []
    for i in range(N):
        row = []
        for j in range(D):
            val = sum(x[i][k] * w1[k][j] for k in range(D)) + b1[j]
            row.append(max(0.0, val))
        h1.append(row)

    out = []
    for i in range(N):
        row = []
        for j in range(D):
            val = sum(h1[i][k] * w2[k][j] for k in range(D)) + b2[j]
            res = x[i][j] + val
            row.append(round(max(0.0, res), 4))
        out.append(row)
    return out
```

A residual block computes F(x) = W2 * ReLU(W1 * x + b1) + b2, then applies an outer ReLU to the sum F(x) + x.
