## Overview

Implement weighted score fusion between dense (embedding) and sparse (BM25-style) retrieval, the real backbone of hybrid search.

## Task

Implement `fuse_scores(dense_scores, sparse_scores, alpha)`. For every doc id in either dict, fused score is `alpha*dense_scores.get(id,0) + (1-alpha)*sparse_scores.get(id,0)`. Return a dict of id -> fused score.
