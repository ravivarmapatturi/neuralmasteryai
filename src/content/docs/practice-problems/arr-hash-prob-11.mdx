## Overview

Implement `group_anagrams(words)`, using each word's own sorted letters as a canonical hash-map key -- the general pattern for "bucket items by a derived signature," not just for anagrams.

## Task

Implement the function `group_anagrams(words)`: group words that are anagrams of each other. Return the groups sorted by their sorted-letters key in ascending alphabetical order; within each group, preserve the words' original relative order.
