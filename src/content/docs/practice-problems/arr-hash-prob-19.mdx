## Overview

Implement `length_of_longest_substring(s)` using a variable-length sliding window and index hash map to compute the longest unique-character substring in O(n) time.

## Task

Implement the function `length_of_longest_substring(s)`: return the length of the longest substring within `s` that contains no repeated characters.
