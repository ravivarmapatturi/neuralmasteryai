## Overview

Build and query a prefix tree supporting dictionary insertion, exact lookup, and prefix matching.

## Task

Implement `simulate_trie(operations)`: simulate a Trie tree. Support operations `insert`, `search` (returns boolean indicating exact word match), and `starts_with` (returns boolean indicating if any inserted word starts with the prefix). Return list of booleans resulting from `search` and `starts_with` calls.

<Solution>

```python
def simulate_trie(operations):
    class TrieNode:
        def __init__(self):
            self.children = {}
            self.is_end = False

    root = TrieNode()
    out = []
    for op in operations:
        action = op.get('op')
        word = op.get('word', '')
        if action == 'insert':
            curr = root
            for ch in word:
                if ch not in curr.children:
                    curr.children[ch] = TrieNode()
                curr = curr.children[ch]
            curr.is_end = True
        elif action == 'search':
            curr = root
            found = True
            for ch in word:
                if ch not in curr.children:
                    found = False
                    break
                curr = curr.children[ch]
            out.append(found and curr.is_end)
        elif action == 'starts_with':
            curr = root
            found = True
            for ch in word:
                if ch not in curr.children:
                    found = False
                    break
                curr = curr.children[ch]
            out.append(found)
    return out
```

Character-by-character branch navigation yields optimal O(length) queries independent of total stored vocabulary size.
