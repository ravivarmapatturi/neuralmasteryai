```python
def middle_node(head):
    slow = head
    fast = head
    while fast and fast.get('next'):
        slow = slow.get('next')
        fast = fast['next'].get('next')
    return slow
```

Because fast travels twice as fast as slow, slow lands exactly on the midpoint when fast reaches the end.
