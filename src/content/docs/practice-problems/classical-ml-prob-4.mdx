```python
def kmeans_update_centroids(points, assignments, k):
    if not points:
        return []
    d = len(points[0])
    sums = [[0.0] * d for _ in range(k)]
    counts = [0] * k
    for p, c in zip(points, assignments):
        if 0 <= c < k:
            counts[c] += 1
            for j in range(d):
                sums[c][j] += p[j]
    centroids = []
    for c in range(k):
        if counts[c] > 0:
            centroids.append([round(sums[c][j] / counts[c], 6) for j in range(d)])
        else:
            centroids.append([0.0] * d)
    return centroids
```

The update step minimizes the within-cluster sum of squares for the given partition, completing one EM iteration of K-Means.
