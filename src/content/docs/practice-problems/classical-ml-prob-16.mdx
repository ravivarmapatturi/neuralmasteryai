```python
import math

def complete_linkage_distance(cluster_a, cluster_b):
    max_d = 0.0
    for pt_a in cluster_a:
        for pt_b in cluster_b:
            d = math.sqrt(sum((x - y) ** 2 for x, y in zip(pt_a, pt_b)))
            if d > max_d:
                max_d = d
    return round(float(max_d), 4)
```

Complete linkage computes the diameter of the merged cluster, creating compact, spherical clusters in agglomerative hierarchical clustering.
