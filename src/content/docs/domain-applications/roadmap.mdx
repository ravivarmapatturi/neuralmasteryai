## Common mistakes

| Mistake | Why it happens | Fix |
| --- | --- | --- |
| Assuming one domain represents all | Constraints vary by field | Read the domain-specific chapter |
| Choosing a model before the task | Requirements determine a useful method | Start from the decision and evidence |
| Ignoring human review | High-impact decisions need oversight | Specify who reviews model output |

## When not to use it

| Situation | Better choice |
| --- | --- |
| You need a complete clinical workflow design | Use the specialized healthcare guidance for the intended jurisdiction |
| You need algorithm derivations | Use the model-specific chapters |
