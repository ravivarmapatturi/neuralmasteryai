# LLMs & GenAI — Roadmap

<ELI5>

A language model has several stages. First, it learns patterns from text. Then people shape how it responds. An application can add instructions and documents, and a serving system turns requests into answers. This route links those pieces in order.

</ELI5>

## Why it exists

The roadmap connects the LLM track’s mechanisms in a study order: transformer internals, training, prompting and APIs, retrieval, evaluation, and multimodal generation. The route helps learners choose the chapter that answers their current systems question.

## Common mistakes

| Mistake | Why it happens | Fix |
| :--- | :--- | :--- |
| Read chapters in framework order alone | The roadmap follows systems dependencies | Start from the behavior or bottleneck you need to understand |
| Treat prompt, retrieval, and serving as one layer | Each changes a different part of system behavior | Identify the layer before selecting the chapter |
| Skip evaluation | A plausible output can still fail the task | Read the evaluation chapter before deployment |

## When not to use it

| Situation | Better choice |
|---|---|
| A single-stage question with no learning-path decision | Use the specific chapter directly |
