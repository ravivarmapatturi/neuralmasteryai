# The Neural Mastery Roadmap

One path through everything on this site, from zero to job-ready. Each section links to its own detailed roadmap — this page is the map of the map.

Want a priority-ranked shortcut instead? See [Suggested Paths](/docs/roadmaps/suggested-paths) for a single list of skills ranked by how often real high-paying ML/AI/GenAI job postings actually ask for them.

## Beginner Track — Foundations
1. [CS Fundamentals for AI Engineers](/docs/cs-fundamentals/roadmap) — operating systems, concurrency, networking, distributed systems, Linux/Git, software engineering practice
2. [Python Engineering for AI](/docs/python-engineering/roadmap) — OOP & functional Python, decorators & generators, async/concurrency, memory management, packaging, testing, tooling
3. [Mathematics for AI](/docs/mathematics-for-ai/roadmap) — linear algebra, calculus, probability, algorithms & data structures
4. [Machine Learning](/docs/machine-learning/roadmap) — classical algorithms, evaluation, the ML workflow

## Intermediate Track — Deep Learning & Modern AI
5. [Deep Learning](/docs/deep-learning/roadmap) — neural networks, CNNs, sequence models, attention & Transformers
6. [Computer Vision](/docs/computer-vision/roadmap) — image fundamentals, the vision task taxonomy, modern/multimodal vision
7. [NLP](/docs/nlp/roadmap) — classical NLP, word embeddings, the task taxonomy underneath modern LLMs
8. [Speech & Audio AI](/docs/speech-audio/roadmap) — signal processing, spectrograms/MFCCs, ASR, TTS, speaker recognition, diarization
9. [LLMs & GenAI](/docs/llms-genai/roadmap) — foundation models, training pipelines, prompt engineering, RAG, evaluation
10. [Databases](/docs/databases/roadmap) — relational, vector (ChromaDB & friends), graph (Neo4j) — needed in parallel with RAG

13. [ML System Design](/docs/ml-system-design/roadmap) — the 9-step framework, recommendation/search/GenAI system case studies
14. [MLOps](/docs/mlops/roadmap) — data/experiment versioning, pipelines, containers, Kubernetes, CI/CD, monitoring, LLMOps & RAGOps
15. [Frameworks](/docs/frameworks/roadmap) — PyTorch, LangChain, MCP SDKs, serving & LLMOps tooling

20. [Graph ML](/docs/graph-ml/roadmap) — GNNs, graph embeddings, knowledge graphs, Graph RAG

## Job-Ready Track
26. [Interview Prep](/docs/interview-prep/roadmap) — DSA, ML coding, knowledge Q&A, system design, behavioral

## How to use this roadmap
- Each section's roadmap is a checklist — work through it top to bottom, and don't skip the "Common Problems & SOTA Solutions" parts. Interviews (and real jobs) test whether you know *why* a technique exists, not just its name.
- The math and ML foundations aren't optional even if you only care about LLMs/agents — attention is linear algebra, RLHF is optimization, and evaluation is statistics.
- Revisit Interview Prep continuously, not just at the end — it's the fastest way to find your weak spots early.
