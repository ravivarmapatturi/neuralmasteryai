# Suggested Paths

[The Neural Mastery Roadmap](/docs/roadmaps/overview) is the complete, zero-to-job-ready path through every section. This page is different: it's a single, flat, **priority-ranked list of the specific skills that show up most often in real high-paying ML/AI/GenAI job postings** — not a tour of this site's sections, a direct answer to "what do I actually need to know to crack this role, in order of how much it matters."

The ranking isn't a guess. It's built from a real sample of current India-market AI-engineer job descriptions (₹30–85 LPA range, senior AI/GenAI engineer roles) plus published salary-band research, counting how many of those postings actually asked for each skill. **Must-Learn** = asked for in most of the sample. **High Priority** = asked for repeatedly, a real ceiling-raiser. **Niche** = fewer roles want it, but a real differentiator when they do. Work top to bottom; by the time you're through Must-Learn you can already hold your own in most interviews for this role.

## Tier 1 — Must-Learn

The skills that showed up in the large majority of real job postings sampled. If you only have time for one tier, this is it.

1. **Multi-agent systems & agent architectures** — [Agent Architectures](/docs/agents/agent-architectures), [Agents Roadmap](/docs/agents/roadmap). Every one of these postings wants production multi-agent systems, not agent demos/POCs.
2. **Tool use, planning, orchestration, agent state & routing** — [ReAct Agent in Production](/docs/agents/react-agent-production). The actual engineering behind "the agent calls a tool and decides what's next" — parse-failure recovery, context growth, loop guards.
3. **RAG pipelines — chunking, hybrid search, reranking** — [RAG](/docs/llms-genai/rag). Still the backbone of most real GenAI products; interviewers probe specifically on chunking strategy and why hybrid beats pure vector search.
4. **Fine-tuning — PEFT / LoRA** — [Training Pipeline](/docs/llms-genai/training-pipeline). The cheap, practical way real teams adapt a base model instead of training from scratch.
5. **Production Python — async, Pydantic, type hints** — [Python Engineering Roadmap](/docs/python-engineering/roadmap). Not "I know Python" — specifically the patterns that show up in every FastAPI-backed AI service's codebase.
6. **Cloud deployment at scale — AWS / GCP / Azure** — [Cloud Computing](/docs/mlops/cloud-computing), [Cloud Model Deployment](/docs/mlops/cloud-model-deployment). Running it on your laptop and running it in production are different skills; this is the second one.
7. **Ownership, mentoring, and startup-grade execution** — the single most-requested trait across the whole sample, and it's not a page you read. It's demonstrated in the interview itself: have a specific story ready where you owned a messy, ambiguous problem end-to-end (not just the code — the decision-making, the tradeoffs, what you'd do differently) and, if relevant, a time you unblocked or mentored someone else on your team.
