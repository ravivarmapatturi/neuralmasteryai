# AI Engineering Track

A structured, 6-stage path through AI engineering — the same shape a focused bootcamp or course would use. Every link below goes to a real, existing, in-depth page on this site; nothing here is a placeholder. If a stage looks thin, that's an honest signal of where this site's own coverage is lighter, not a hidden page.

This is a *curated sequence* through content that already exists elsewhere on the site (same pattern as [Suggested Paths](/docs/roadmaps/suggested-paths), just organized as a linear course instead of a priority-ranked list) — not a duplicate curriculum.

## 01 · AI Engineering Foundations

The core skills every production AI engineer needs before touching an LLM: systems, Python, and math.

- [CS Fundamentals for AI Engineers](/docs/cs-fundamentals/roadmap) — 7 pages
- [Python Engineering for AI](/docs/python-engineering/roadmap) — 5 pages
- [Mathematics for AI](/docs/mathematics-for-ai/roadmap) — 6 pages

- [Calling the LLM API in Practice](/docs/llms-genai/calling-the-llm-api) — streaming, retries, parameters, and what to log on every call

## 02 · Building RAG Systems

Retrieval-augmented generation end to end — chunking, embeddings, hybrid search, reranking, and real evaluation, not a toy vector-DB demo.

- [Retrieval-Augmented Generation (RAG)](/docs/llms-genai/rag) — chunking strategies, dense/sparse/hybrid retrieval, advanced RAG architectures, GraphRAG, real eval metrics
- [Retrieval & Reranking Architectures](/docs/llms-genai/retrieval-and-reranking-architectures) — bi-encoder, cross-encoder, late interaction
- [Prompt Engineering](/docs/llms-genai/prompt-engineering) — structured output, system prompts
- [Evaluation & Serving](/docs/llms-genai/evaluation-and-serving)

## 04 · LLMOps & Production
