## 7. Common Problems & SOTA Solutions
- [x] **Agent loses context over long tasks** → memory systems, summarization, external state stores
- [x] **Agent gets stuck in loops** → step limits, reflection checkpoints, human-in-the-loop escalation
- [x] **Tool-calling hallucination** (calling tools that don't exist, malformed args) → strict schemas, validation, retries
- [x] **Runaway cost/latency in multi-agent chains** → caching, cheaper models for sub-tasks, parallelization

## Common mistakes

| Mistake | Why it happens | Fix |
| :--- | :--- | :--- |
| Start with a framework before learning the loop | Later abstractions lack a mechanism | Begin with Agent Fundamentals |
| Treat MCP and A2A as the same boundary | Tool access and agent delegation differ | Choose the chapter matching the connection |
| Skip long-task recovery | Plans and actions can fail silently | Include harness verification and recovery |

## When not to use it

| Situation | Better choice |
|---|---|
| A small, deterministic task with no adaptive decisions | Use direct code or an ordinary workflow |
