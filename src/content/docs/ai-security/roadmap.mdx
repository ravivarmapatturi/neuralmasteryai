## Common mistakes

| Mistake | Why it happens | Fix |
| :--- | :--- | :--- |
| Begin with red-team payloads without a threat model | Tests may miss the relevant boundary | Map the attack surface before selecting probes |
| Confuse security and alignment | Adversarial compromise differs from well-intentioned failure | Use the linked AI Safety path for alignment questions |
| End after classifying a vulnerability | Labels do not prove controls work | Run a system test and verify the mitigation |
