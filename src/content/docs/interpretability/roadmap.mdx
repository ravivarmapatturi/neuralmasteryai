## Common mistakes

| Mistake | Why it happens | Fix |
| --- | --- | --- |
| Starting with circuits before attribution basics | Internal mechanisms require model context | Begin with the classical page |
| Assuming all methods are equally causal | Evidence strength varies | Use the rigor ladder |
| Ignoring explanation stability | One run can be misleading | Check repeatability |

## When not to use it

| Situation | Better choice |
| --- | --- |
| You need a plain metric dashboard | Use model evaluation |
| You need only predictions, not explanations | Skip interpretability methods |
