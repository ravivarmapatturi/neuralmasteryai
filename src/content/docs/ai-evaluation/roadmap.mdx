## Common mistakes

| Mistake | Why it happens | Fix |
| :--- | :--- | :--- |
| Begin with judge prompts before checking the dataset | An invalid benchmark produces misleading judgments | Validate the measure and test set first |
| Skip human review | Automated graders can share model biases | Use people for subjective or high-impact criteria |
| Omit adversarial cases | Routine inputs miss attack behavior | Include red-team inputs in the test plan |
