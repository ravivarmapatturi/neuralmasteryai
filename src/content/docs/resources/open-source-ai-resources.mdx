# Open Source AI Resources

## Why it exists

Learning improves when explanations, practice and system examples connect. This page groups resources by the skill they support so you can choose a useful next step.

A running list of free, high-quality resources outside Neural Mastery — for deeper practice, alternative explanations, or interview drilling. This page gets updated as new ones are found; it's a tab, not a one-time list.

## Interview Prep
- **[amitshekhariitbhu/ai-engineering-interview-questions](https://github.com/amitshekhariitbhu/ai-engineering-interview-questions)** (Apache-2.0) — large Q&A bank covering LLM fundamentals, RAG, agents, fine-tuning, evaluation, and scenario-based "your system is failing like X" questions.
- **[alirezadir/AIMLInterviews](https://github.com/alirezadir/AIMLInterviews)** (MIT) — structured chapters: DSA, ML coding, ML fundamentals, ML/GenAI system design, agentic AI systems, behavioral.
- **[chiphuyen/ml-interviews-book](https://huyenchip.com/ml-interviews-book/)** (© Chip Huyen) — free web book covering the interview process plus 200+ classical ML knowledge questions.

## Math Intuition
- **[3Blue1Brown — Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra)** and **[Essence of Calculus](https://www.3blue1brown.com/topics/calculus)** — visual, intuition-first explanations.

## System Design
- **[Chip Huyen — Machine Learning Systems Design: 30 open-ended questions](https://huyenchip.com/machine-learning-systems-design/toc.html)** — companion to her Stanford course CS 329S.

## Agentic AI
- **[alirezadir/Agentic-AI-Systems](https://github.com/alirezadir/Agentic-AI-Systems)** (MIT) — dedicated deep dive on agent architectures.
