## Common mistakes

| Mistake | Why it happens | Fix |
| --- | --- | --- |
| Starting with task models before signal basics | Input representations may be unclear | Begin with audio fundamentals |
| Comparing systems with one score | Tasks measure different outcomes | Use the matching metric |
| Ignoring latency requirements | Streaming and offline differ | Set timing constraints first |
