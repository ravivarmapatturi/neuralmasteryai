## Common mistakes

| Mistake | Why it happens | Fix |
| --- | --- | --- |
| Reading timelines without methods | The individual contribution remains unclear | Start with one paper |
| Ignoring follow-up work | Claims can change over time | Read later evaluations |
| Assuming the order is exhaustive | A timeline selects representative work | Use citations to branch further |

## When not to use it

| Situation | Better choice |
| --- | --- |
| You need a coding-first path | Use projects or implementation tracks |
| You need one paper’s exact details | Open the paper directly |
