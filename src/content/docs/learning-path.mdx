# Learning Path

The curriculum is seven sections, and each one leans on the ones before it. If you're not sure what to read next, go top to bottom. If you already know a section (say you're comfortable with the math), skip it; the order is a suggestion, not a gate.

The counts under each section come from the "Mark as understood" button at the bottom of every page. That's stored in your browser only, and the full checklist is on [Progress](/progress).

If you'd rather work backwards from a job, [Suggested Paths](/docs/roadmaps/suggested-paths) orders topics by how often they come up in ML and AI job postings.
