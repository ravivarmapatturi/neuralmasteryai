## 12. Common Problems & SOTA Solutions
- [x] **Vanishing gradients in deep nets** → residual connections, normalization
- [x] **Overfitting on limited image data** → data augmentation, transfer learning, pretrained backbones
- [x] **Quadratic cost of self-attention on long sequences** → Flash Attention, or [linear attention and Mamba-style state-space models](/docs/deep-learning/linear-attention-and-state-space-models)
- [x] **Slow inference** → quantization, distillation, pruning
- [x] **Training instability at scale** → careful init, warmup, gradient clipping, mixed precision
