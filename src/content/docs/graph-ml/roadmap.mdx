## Common mistakes

| Mistake | Why it happens | Fix |
| --- | --- | --- |
| Starting from an architecture name | The target may be node, edge or graph | Choose the task first |
| Ignoring arbitrary node order | A relabeling should not change meaning | Use invariant representations |
| Treating roadmap as exhaustive | The section may grow over time | Follow the linked fundamentals page |
