# Graph ML — Overview

<ELI5>

Many datasets are about relationships: users connect to items, atoms bond in molecules, and papers cite papers. Graph ML represents those entities and edges so a prediction can use structure as well as features.

</ELI5>

[Advanced Architectures — GNNs](/docs/deep-learning/advanced-architectures#graph-neural-networks-gnns) introduced message passing and the GCN/GraphSAGE/GAT architecture family. This section is the rest of the graph-ML picture: the task taxonomy those architectures actually solve, graph embedding methods that predate (and still compete with) GNNs, knowledge graphs, and how graph structure shows up in modern LLM systems via Graph RAG.

## Why it exists

Many datasets are about relationships: users connect to items, atoms bond in molecules, and papers cite papers. Graph ML represents those entities and edges so a prediction can use structure as well as features.
