## Common mistakes

| Mistake | Why it happens | Fix |
| --- | --- | --- |
| Flattening away edges | Relational signals disappear | Keep adjacency and edge features |
| Assuming node order has meaning | Graph labels are arbitrary | Use permutation-invariant methods |
| Using a graph model for unrelated data | Extra structure adds complexity | Confirm relationships help the task |

## When not to use it

| Situation | Better choice |
| --- | --- |
| Examples have no meaningful relations | Use tabular or sequence models |
| You need only a graph database query | Use graph traversal or database queries |
