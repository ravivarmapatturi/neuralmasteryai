## Common mistakes

| Mistake | Why it happens | Fix |
| --- | --- | --- |
| Choosing a framework before requirements | Extra abstractions add complexity | Start from the task and runtime |
| Confusing framework with model | A library does not determine model quality | Compare model and tooling separately |
| Ignoring deployment integration | A prototype may not ship | Check serving and operations early |

## When not to use it

| Situation | Better choice |
| --- | --- |
| A small script needs no abstraction | Use the core library directly |
| A framework cannot meet security or latency requirements | Use a narrower custom integration |
